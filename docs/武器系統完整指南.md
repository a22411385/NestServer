# 武器系統完整指南

## 📋 系統概覽

RPG 武器系統是一個完全配置驅動的現代化武器管理系統，支持完整的屬性系統、品質等級、掉落機制和實例管理。

### 🎯 核心特性

- **配置驅動**：所有武器屬性來自 Google Sheets
- **零參數初始化**：武器類不需要構造函數參數
- **完整屬性系統**：支持固定屬性和隨機屬性
- **品質等級**：5 個品質等級，影響隨機屬性數量
- **智能掉落**：基於敵人等級的掉落系統
- **實例管理**：高效的緩存和生命週期管理
- **唯一 ID 系統**：統一的 ID 生成策略

## 🏗️ 系統架構

### 三層架構設計

```
🎮 門面層 (Facade)     - WeaponSystemFacade
⚙️  服務層 (Service)    - WeaponDataService, WeaponPropertyService
📊 管理層 (Manager)     - WeaponInstanceManager, WeaponFactory
```

#### 核心組件

- **WeaponSystemFacade**: 統一接口，簡化複雜操作
- **WeaponInstanceManager**: 實例創建、緩存和生命週期管理
- **WeaponDataService**: 業務邏輯計算（屬性、升級等）
- **WeaponFactory**: 武器創建工廠
- **WeaponPropertyService**: 屬性生成系統

## 🚀 快速開始

### 1. 系統初始化

```typescript
import { WeaponSystemFacade } from '@/Game/Systems/WeaponSystemFacade';

// 應用程序啟動時初始化
async function initializeWeaponSystem() {
    WeaponSystemFacade.initialize();
    console.log('✅ 武器系統初始化完成');
}
```

### 2. 創建武器

```typescript
// 🆕 現代方式（配置驅動）
const { data, instance, stats } = WeaponSystemFacade.createAndGetWeapon('fireball');

// 或使用工廠直接創建
const weapon = WeaponFactory.createWeapon('fireball');
```

### 3. 獲取完整武器實例

```typescript
const weaponData = new WeaponData('sword');
const { instance, stats } = WeaponSystemFacade.getCompleteWeaponInstance(weaponData);

console.log(`武器名稱: ${stats.displayName}`);
console.log(`最終攻擊力: ${stats.finalDamage}`);
```

## 📊 配置系統

### Google Sheets WeaponConfigs 格式

```typescript
interface WeaponConfig {
    id: string;              // 武器ID
    name: string;            // 顯示名稱
    baseDamage: number;      // 基礎攻擊力
    attackSpeed: number;     // 攻擊間隔(ms)
    attackRange: number;     // 攻擊距離
    enabled: boolean;        // 是否啟用
    weaponClass: string;     // 武器類別名稱
    classModule: string;     // 模組類型
    fixedProperties: string; // 固定屬性(逗號分隔)
    randomProperties: string;// 隨機屬性池(逗號分隔)
    description: string;     // 武器描述
}
```

### 武器分類

- **MeleeWeapon**: 近戰武器 (球棒、匕首、戰錘等)
- **ProjectileWeapon**: 投射武器 (火球、冰球、閃電等)
- **SupportWeapon**: 支援武器 (治療法杖、治療藥水等)

## 🎲 屬性系統

### 屬性類型

- **固定屬性**: 每個武器固定擁有的屬性
- **隨機屬性**: 根據品質等級隨機生成的屬性

### 品質等級系統

| 品質 | 隨機屬性數 | 掉落機率 | 顏色 |
|------|-----------|----------|------|
| 普通 (NORMAL) | 0個 | 54% | 灰色 |
| 魔法 (MAGIC) | 1個 | 30% | 藍色 |
| 稀有 (RARE) | 2個 | 10% | 黃色 |
| 史詩 (EPIC) | 3個 | 5% | 紫色 |
| 傳奇 (LEGENDARY) | 4個 | 1% | 橙色 |

### 屬性分類

- **基礎屬性**: 攻擊力、攻速、射程等
- **戰鬥效果**: 暴擊、生命偷取、穿透等
- **狀態效果**: 燃燒、冰凍、暈眩等
- **角色屬性**: 力量、敏捷、智力、體力

## 🎁 掉落系統整合

### 智能掉落

```typescript
// 在 DropSystem 中，武器掉落使用完整的武器管理器
private generateCompleteWeapon(enemy: ServerEnemy): WeaponData | null {
    const { data: weaponData } = WeaponSystemFacade.createAndGetWeapon(weaponId);
    
    // 根據敵人等級調整武器等級
    weaponData.level = Math.max(1, enemyLevel + Math.floor(Math.random() * 3) - 1);
    
    return weaponData;
}
```

```typescript
try {
    const weapon = WeaponSystemFacade.createAndGetWeapon(weaponId);

        return;
    }

    console.error('武器系統錯誤:', error);
}
```
