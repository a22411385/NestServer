# 敵人攻擊前搖系統完成報告

## 📋 需求概述

實現敵人攻擊前搖機制，讓攻擊更符合現實邏輯：
- 敵人攻擊時有明顯的前搖動作
- 前搖期間鎖定目標位置
- 前搖完成時檢查目標是否還在範圍內
- 如果目標已離開範圍，攻擊失敗

## ✅ 實現內容

### 1. 新增攻擊狀態機

**檔案**: `NestServer/src/Colyseus/Schema/Unit/Enemy.ts`

#### AI 狀態擴展

**之前**：
```typescript
private aiState: "chase" | "attack" | "idle"
```

**之後**：
```typescript
private aiState: "chase" | "attack" | "windup" | "idle"
```

新增 `windup` 狀態表示攻擊前搖階段。

### 2. 前搖系統屬性

```typescript
// 🆕 攻擊前搖系統
private windupStartTime: number = 0;           // 前搖開始時間
private windupDuration: number = 300;          // 前搖時長 (ms)
private windupTargetId: string = "";           // 前搖時鎖定的目標ID
private windupTargetPosition: {                // 前搖時鎖定的目標位置
    x: number, 
    y: number 
} | null = null;
```

### 3. 攻擊流程重構

#### 舊流程（立即攻擊）
```
進入攻擊範圍 → 立即造成傷害 → 冷卻
```

#### 新流程（前搖系統）
```
進入攻擊範圍 
  ↓
開始前搖 (windup state)
  - 鎖定目標ID和位置
  - 停止移動 (vx=0, vy=0)
  - 設置 isAttacking = true
  ↓
等待前搖時間 (windupDuration)
  ↓
前搖完成
  ↓
檢查目標狀態：
  - 目標死亡/消失？ → 攻擊失敗 ❌
  - 目標超出範圍？ → 攻擊失敗 ❌
  - 目標仍在範圍內 → 執行攻擊 ✅
  ↓
返回追擊狀態
```

### 4. 核心方法實現

#### `attemptAttack()` - 啟動前搖

```typescript
private attemptAttack(target: ServerHero, currentTime: number): boolean {
    // 檢查攻擊冷卻
    if (currentTime - this.lastAttackTime < this.attackSpeed) {
        return false;
    }

    // 🆕 開始前搖
    this.windupStartTime = currentTime;
    this.windupTargetId = target.id;
    this.windupTargetPosition = { x: target.position.x, y: target.position.y };
    this.aiState = "windup";
    this.isAttacking = true;
    this.attackStartTime = currentTime; // 用於前端動畫同步
    
    // 更新最後攻擊時間（包含前搖時間）
    this.lastAttackTime = currentTime;

    console.log(`⚔️ Enemy ${this.id} starts windup (${this.windupDuration}ms)`);
    
    return true;
}
```

#### `handleWindup()` - 處理前搖階段

```typescript
private handleWindup(currentTime: number): void {
    const windupElapsed = currentTime - this.windupStartTime;
    
    // 前搖期間保持靜止
    this.vx = 0;
    this.vy = 0;
    
    // 前搖完成，執行實際攻擊
    if (windupElapsed >= this.windupDuration) {
        this.executeAttack(currentTime);
    }
}
```

#### `executeAttack()` - 執行實際攻擊

```typescript
private executeAttack(currentTime: number): void {
    const target = this.targetCache;
    
    // 檢查1：目標是否還存在
    if (!target || target.isDead) {
        console.log(`❌ Enemy ${this.id} attack failed - target lost`);
        this.resetAttackState();
        return;
    }

    // 檢查2：目標是否還在攻擊範圍內
    const distanceToTarget = this.getDistanceTo(target);
    if (distanceToTarget > this.attackRange) {
        console.log(`❌ Enemy ${this.id} attack failed - out of range`);
        this.resetAttackState();
        return;
    }

    // ✅ 執行攻擊
    console.log(`✅ Enemy ${this.id} successfully hit hero ${target.id}`);
    this.attackTarget(target);
    this.resetAttackState();
}
```

### 5. 不同敵人類型的前搖配置

| 敵人類型 | 前搖時間 | 攻擊傷害 | 攻擊間隔 | 設計理念 |
|---------|---------|---------|---------|---------|
| **普通殭屍** (Lv1) | 300ms | 10 | 1000ms | 平衡型，給玩家反應時間 |
| **快速殭屍** (Lv2) | 200ms | 8 | 800ms | 前搖快但傷害低 |
| **強壯殭屍** (Lv3) | 400ms | 15 | 1500ms | 前搖慢但傷害高，更好躲避 |

```typescript
initializeByType(lv: number): void {
    switch (lv) {
        case 1:
            this.windupDuration = 300; // 標準前搖
            break;
        case 2:
            this.windupDuration = 200; // 快速前搖
            break;
        case 3:
            this.windupDuration = 400; // 緩慢前搖（高傷害）
            break;
    }
}
```

### 攻擊失敗的條件

1. **目標消失**
   ```typescript
   if (!target || target.isDead) {
       // 攻擊失敗
   }
   ```

2. **目標脫離範圍**
   ```typescript
   const distance = this.getDistanceTo(target);
   if (distance > this.attackRange) {
       // 攻擊失敗
   }
   ```

### 時間軸範例

```
時間軸 (以 Lv1 普通殭屍為例):

T=0ms    : 敵人進入攻擊範圍 (60像素)
T=0ms    : 調用 attemptAttack()
           - 設置 windupStartTime = 0
           - aiState = "windup"
           - isAttacking = true
           - 停止移動 (vx=0, vy=0)

T=100ms  : handleWindup() 檢查
           - 前搖進度: 100/300ms (33%)
           - 繼續等待

T=200ms  : handleWindup() 檢查
           - 前搖進度: 200/300ms (66%)
           - 繼續等待

T=300ms  : handleWindup() 檢查
           - 前搖進度: 300/300ms (100%)
           - 調用 executeAttack()
           
           執行攻擊判定：
           Case 1: 玩家還在範圍內 → ✅ 造成傷害
           Case 2: 玩家已離開範圍 → ❌ 攻擊失敗

T=300ms+ : 返回追擊狀態
           - aiState = "chase"
           - isAttacking = false

T=1000ms : 攻擊冷卻完成，可以再次攻擊
```

## 🔧 可調整參數

### 1. 前搖時長
```typescript
this.windupDuration = 300; // 調整這個值改變前搖時間
```
- 建議範圍：150ms - 500ms
- 太短：玩家反應不及
- 太長：敵人攻擊效率太低

### 2. 攻擊範圍與前搖的平衡
```typescript
this.attackRange = 60;      // 攻擊範圍
this.windupDuration = 300;  // 前搖時間
this.moveSpeed = 50;        // 移動速度
```

計算玩家逃跑距離：
```
玩家移動速度 = 100 像素/秒 (假設)
前搖時間 = 300ms = 0.3秒
可逃跑距離 = 100 * 0.3 = 30 像素

如果 攻擊範圍 = 60，玩家需要在攻擊範圍邊緣才能成功逃脫
```

### 3. 攻擊冷卻
```typescript
this.attackSpeed = 1000; // 攻擊間隔（包含前搖）
```
- 實際攻擊頻率 = 1 / (attackSpeed / 1000)
- 1000ms = 1 次/秒

## 🐛 已處理的邊緣情況

1. **目標在前搖期間死亡** → 攻擊失敗，不造成傷害
2. **目標被擊退脫離範圍** → 攻擊失敗
3. **敵人在前搖期間被控制** → 前搖不會被打斷（可擴展）
4. **多個敵人同時前搖同一目標** → 各自獨立判定
