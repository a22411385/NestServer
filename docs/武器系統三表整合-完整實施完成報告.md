## 🎯 項目總覽

本次重構實現了一個**完全配置驅動**的武器屬性系統，整合三種不同類型的武器屬性：

1. **狀態效果** (StatusEffects) - 臨時作用於目標的效果
2. **武器詞綴** (WeaponModifiers) - 影響武器攻擊機制的特性
3. **屬性加成** (AttributeBonuses) - 永久增強角色屬性

**核心優勢**：
- ✅ 零 hardcode，所有映射由 Google Sheets 配置
- ✅ POE 風格修改器系統（FLAT → INCREASED → MORE）
- ✅ 支援動態擴展，新增屬性無需修改代碼
- ✅ 完整的向下相容性

#### 3.1 ServerHero.ts

**更新 updateWeaponAttributeBonuses()**：
```typescript
private updateWeaponAttributeBonuses(): void {
    // 1. 收集所有武器的 bonuses
    const allBonuses: any[] = [];
    for (const weapon of this.weaponInventory) {
        const weaponSchema = this.findWeaponSchemaById(weapon.uniqueId);
        if (weaponSchema) {
            // 舊版屬性（向下相容）
            this.weaponStr += weaponSchema.str || 0;
            
            // 新版屬性加成
            const bonuses = weaponSchema.getBonuses();
            if (bonuses && bonuses.length > 0) {
                allBonuses.push(...bonuses);
            }
        }
    }
    
    // 2. 應用收集到的屬性加成
    if (allBonuses.length > 0) {
        this.applyEquipmentBonus(allBonuses);
    }
}
```

**重構 applyEquipmentBonus()**：
```typescript
public applyEquipmentBonus(bonuses: AttributeBonus[]): void {
    // 檢測是否為新版系統
    const isNewSystem = bonuses.some(b => (b as any).affectedStat);
    
    if (isNewSystem) {
        // 配置驅動系統
        this.applyConfigDrivenBonuses(bonuses);
    } else {
        // 舊版 hardcode 系統（向下相容）
        // ...
    }
}
```

**新增 applyConfigDrivenBonuses()**：
```typescript
private applyConfigDrivenBonuses(bonuses: any[]): void {
    // 1. 按 affectedStat 分組
    const bonusesByAffectedStat = new Map<string, any[]>();
    
    // 2. 對每個屬性應用 POE 規則
    for (const [affectedStat, statBonuses] of bonusesByAffectedStat) {
        this.applyBonusToStat(affectedStat, statBonuses);
    }
}
```

**新增 applyBonusToStat()**：
```typescript
private applyBonusToStat(affectedStat: string, bonuses: any[]): void {
    // 1. 分類加成 (FLAT, INCREASED, MORE)
    // 2. 計算最終值
    // 3. 映射到 Hero 屬性
    this.applyStatBonus(affectedStat, flatSum, increasedSum, moreProduct);
}
```

**新增 applyStatBonus()**：
```typescript
private applyStatBonus(
    affectedStat: string,
    flatSum: number,
    increasedSum: number,
    moreProduct: number
): void {
    // 屬性映射表
    const statMapping: Record<string, { base, multiplier }> = {
        'strength': { 
            base: 'weaponStr', 
            multiplier: 'attackMultiplier' 
        },
        'agility': { 
            base: 'weaponAgi', 
            multiplier: 'speedMultiplier' 
        },
        'intelligence': { 
            base: 'weaponInt', 
            multiplier: 'mpMultiplier' 
        },
        'vitality': { 
            base: 'weaponVit', 
            multiplier: 'hpMultiplier' 
        },
        'attack_damage': { 
            base: 'equipmentAttackBonus', 
            multiplier: 'attackMultiplier' 
        },
        'max_health': { 
            base: 'equipmentHpBonus', 
            multiplier: 'hpMultiplier' 
        }
    };
    
    // 應用 FLAT 和 INCREASED/MORE
}
```
