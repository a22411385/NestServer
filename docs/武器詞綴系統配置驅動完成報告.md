### 2. 配置驅動的詞綴應用

**核心方法**: `applyWeaponModifiers()`

```typescript
private static applyWeaponModifiers(
    weaponData: WeaponSchema, 
    finalStats: FinalWeaponStats
): void {
    // 1. 獲取武器詞綴（從 WeaponSchema.getModifiers()）
    const modifiers = weaponData.getModifiers();
    
    // 2. 按 affectedStat 分組
    const modifiersByAffectedStat = new Map<string, any[]>();
    for (const modifier of modifiers) {
        const affectedStat = modifier.affectedStat; // 來自配置！
        // ...分組邏輯
    }
    
    // 3. 對每個屬性應用 POE 規則計算
    for (const [affectedStat, mods] of modifiersByAffectedStat) {
        this.applyModifiersToStat(affectedStat, mods, finalStats);
    }
}
```

**設計亮點**：
- ✅ **零 hardcode**：所有映射從 `modifier.affectedStat` 讀取
- ✅ **自動分組**：相同 `affectedStat` 的詞綴自動聚合
- ✅ **錯誤容忍**：未知詞綴不會導致系統崩潰

### 3. POE 規則計算引擎

**核心方法**: `applyModifiersToStat()`

```typescript
private static applyModifiersToStat(
    affectedStat: string,      // 例如: "pierce_count"
    modifiers: any[],
    finalStats: FinalWeaponStats
): void {
    // 步驟 1：轉換屬性名 (pierce_count → pierceCount)
    const statKey = this.convertToCamelCase(affectedStat);
    
    // 步驟 2：分類詞綴
    let flatSum = 0;           // FLAT 總和
    let increasedSum = 0;      // INCREASED 總和
    let moreProduct = 1;       // MORE 乘積
    
    for (const modifier of modifiers) {
        const value = modifier.value || modifier.baseValue || 0;
        const type = modifier.modifierType.toLowerCase();
        const count = modifier.count || 1;
        
        switch (type) {
            case 'flat':      flatSum += value * count; break;
            case 'increased': increasedSum += value * count; break;
            case 'more':      moreProduct *= (1 + value * count / 100); break;
        }
    }
    
    // 步驟 3：POE 規則計算
    let finalValue = baseValue;
    finalValue += flatSum;                    // 加上固定值
    finalValue *= (1 + increasedSum / 100);   // 提升加成
    finalValue *= moreProduct;                 // 額外加成
    
    // 步驟 4：設定結果
    (finalStats as any)[statKey] = finalValue;
}
```

**POE 規則示例**：
```
基礎值: 0
FLAT +1, FLAT +2, INCREASED +50%

計算過程:
1. 基礎: 0
2. FLAT: 0 + 1 + 2 = 3
3. INCREASED: 3 * (1 + 0.5) = 3 * 1.5 = 4.5
4. MORE: (如果有) 4.5 * (1 + X%)

結果: pierceCount = 4.5
```

### 4. 自動屬性名轉換

**方法**: `convertToCamelCase()`

```typescript
private static convertToCamelCase(str: string): string {
    return str.replace(/_([a-z])/g, (_, letter) => letter.toUpperCase());
}
```

**轉換示例**：
```
pierce_count      → pierceCount
chain_count       → chainCount
projectile_speed  → projectileSpeed
area_radius       → areaRadius
sweep_angle       → sweepAngle
```

**設計優勢**：
- ✅ 配置使用 snake_case（資料庫友好）
- ✅ TypeScript 使用 camelCase（慣例）
- ✅ 自動轉換，開發者無感
