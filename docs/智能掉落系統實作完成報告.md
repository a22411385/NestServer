## 🎮 掉落機率設計詳情

### 稀有度基礎機率
```typescript
common: 30%      // 普通物品
uncommon: 15%    // 不常見物品  
rare: 5%         // 稀有物品
epic: 1%         // 史詩物品
legendary: 0.1%  // 傳說物品
```

### 物品類型調整係數
```typescript
CURRENCY: 1.5x    // 貨幣類較容易掉落
MATERIAL: 1.0x    // 材料類正常掉落
CONSUMABLE: 0.8x  // 消耗品稍微困難
MISC: 0.6x        // 雜項物品較困難
```

### 分類特殊倍率
```typescript
// 基礎材料 - 較高掉落率
ore: 1.2x, crafting: 1.5x, herb: 1.3x

// 中等稀有度
potion: 0.8x, food: 1.0x, currency: 1.5x

// 稀有物品 - 較低掉落率  
magic: 0.5x, rare_drop: 0.2x, gem: 0.3x, artifact: 0.1x
```

## 🧮 掉落算法邏輯

### 最終掉落機率計算
```
最終機率 = 基礎稀有度機率 × 類型係數 × 分類係數 × 等級係數 × 價值係數
```

### 等級適配機制
- **等級不足**: 掉落率降至 10%
- **等級適合**: 正常掉落率
- **等級過高**: 逐漸降低掉落率 (最低30%)

### 特殊物品等級需求
- **普通材料**: 1級起
- **稀有金屬**: 15-25級起  
- **傳說材料**: 40級起
- **魔法物品**: +10級需求
- **特殊掉落**: +20級需求

## 📊 實際掉落機率範例

### 1級敵人掉落 (以鐵礦石為例)
```
基礎機率: 30% (common)
類型係數: 1.0x (MATERIAL)  
分類係數: 1.2x (ore)
等級係數: 1.0x (適合)
價值係數: 0.89x (baseValue: 5)
最終機率: 30% × 1.0 × 1.2 × 1.0 × 0.89 ≈ 32%
```
