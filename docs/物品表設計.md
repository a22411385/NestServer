# 物品表設計

## 物品分類說明

### 物品類型 (ItemType)
- **MATERIAL**: 材料類 - 用於合成、製作
- **CONSUMABLE**: 消耗品 - 可使用的物品
- **CURRENCY**: 貨幣類 - 金幣、特殊貨幣
- **MISC**: 雜項類 - 任務物品、收藏品

## 品質等級 (Rarity)
- **common** (普通): 白色 - 基礎物品
- **uncommon** (不常見): 綠色 - 稍微稀有
- **rare** (稀有): 藍色 - 珍貴物品
- **epic** (史詩): 紫色 - 非常稀有
- **legendary** (傳說): 橙色 - 極度稀有

## 欄位說明
- **id**: 物品唯一識別碼
- **name**: 物品顯示名稱
- **type**: 物品類型 (MATERIAL/CONSUMABLE/CURRENCY/MISC)
- **description**: 物品描述
- **baseValue**: 基礎價值
- **rarity**: 品質等級
- **stackSize**: 最大堆疊數量
- **sellPrice**: 販賣價格
- **icon**: 圖示名稱
- **category**: 分類
- **usable**: 是否可使用
- **effects**: 使用效果 (格式: 效果類型:數值:持續時間)
