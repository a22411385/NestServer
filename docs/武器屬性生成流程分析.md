# 武器屬性生成流程分析

## 📋 概述

本文檔詳細追蹤武器從創建到屬性生成的完整流程,分析當前實現和潛在問題。

---

## 🔄 完整流程圖

### 場景 1: 玩家添加武器到背包

```
1. HeroWeaponManager.addToInventory(weaponId)
   │
   ├─> 調用 WeaponSystemFacade.createAndGetWeapon(weaponId)
   │   │
   │   ├─> 1.1 創建 WeaponSchema
   │   │   └─> new WeaponSchema(weaponId)
   │   │       ├─> 生成 uniqueId
   │   │       ├─> 從 WeaponConfig 載入基本信息 (name, description)
   │   │       ├─> 從 WeaponConfig 載入固定/隨機屬性列表
   │   │       └─> propertiesJson = "{}" (空)
   │   │
   │   ├─> 1.2 獲取邏輯實例
   │   │   └─> WeaponInstanceManager.getOrCreateInstance(data)
   │   │       │
   │   │       ├─> 檢查緩存 (首次創建,緩存不存在)
   │   │       │
   │   │       └─> createNewInstance(weaponData)
   │   │           │
   │   │           ├─> WeaponFactory.createWeapon(weaponId)
   │   │           │   └─> 返回 MeleeWeapon/ProjectileWeapon/SupportWeapon 實例
   │   │           │
   │   │           ├─> determineWeaponQuality(weaponData)
   │   │           │   ├─> 使用種子生成穩定隨機數
   │   │           │   ├─> 基礎機率: [54,30,10,5,1] (普通,魔法,稀有,史詩,傳奇)
   │   │           │   ├─> 強化等級加成: enhanceLevel * 2%
   │   │           │   ├─> 等級加成: (level-1) * 1%
   │   │           │   └─> 返回 WeaponQuality (如 "rare")
   │   │           │
   │   │           ├─> WeaponPropertyService.generateWeaponProperties(weaponId, quality, seed)
   │   │           │   │
   │   │           │   ├─> 獲取 WeaponConfig
   │   │           │   │
   │   │           │   ├─> 解析固定屬性 (parseFixedProperties)
   │   │           │   │   ├─> 從 config.fixedProperties 字串解析 (如 "knockback,stun")
   │   │           │   │   ├─> 查找屬性定義 (weaponProperties Map)
   │   │           │   │   ├─> 使用最大值生成
   │   │           │   │   └─> 返回 PropertyValue[]
   │   │           │   │
   │   │           │   ├─> 生成隨機屬性 (generateRandomProperties)
   │   │           │   │   ├─> 從 config.randomProperties 解析屬性池
   │   │           │   │   ├─> 根據品質決定隨機屬性數量:
   │   │           │   │   │   - normal: 0個
   │   │           │   │   │   - magic: 1個
   │   │           │   │   │   - rare: 2個
   │   │           │   │   │   - epic: 3個
   │   │           │   │   │   - legendary: 4個
   │   │           │   │   ├─> 使用種子隨機選擇屬性
   │   │           │   │   ├─> 生成隨機數值 (min ~ max 範圍)
   │   │           │   │   └─> 返回 PropertyValue[]
   │   │           │   │
   │   │           │   └─> 合併固定屬性 + 隨機屬性,返回完整列表
   │   │           │
   │   │           ├─> ✅ instance.applyProperties(properties)
   │   │           │   └─> WeaponBasic 內部更新:
   │   │           │       - baseDamage, attackSpeed, attackRange
   │   │           │       - str, int, agi, vit
   │   │           │       - properties Map
   │   │           │
   │   │           ├─> ✅ weaponData.setProperties(properties)
   │   │           │   └─> WeaponSchema 更新:
   │   │           │       - propertiesJson = JSON.stringify(...)
   │   │           │       - 同步到客戶端!
   │   │           │
   │   │           ├─> ✅ weaponData.quality = quality
   │   │           │
   │   │           └─> 返回 WeaponBasic 實例
   │   │
   │   └─> 1.3 計算最終屬性 (可選)
   │       └─> WeaponDataService.calculateFinalStats(data)
   │
   └─> 2. 添加到背包
       └─> hero.weaponInventory.push(data)
           └─> 觸發 Colyseus 同步到客戶端
```

## 🔍 關鍵代碼分析

### 1. WeaponInstanceManager.createNewInstance()

**位置:** `src/Game/Managers/WeaponInstanceManager.ts:76`

```typescript
private static createNewInstance(weaponData: WeaponData): WeaponBasic | null {
    // 1. 創建基礎實例
    const instance = WeaponFactory.createWeapon(weaponData.weaponId);
    
    // 2. 確定品質
    const quality = this.determineWeaponQuality(weaponData);
    
    // 3. 生成屬性
    const properties = propertyService.generateWeaponProperties(
        weaponData.weaponId,
        quality,
        this.generateSeed(weaponData)
    );
    
    // 4. ✅ 應用到 WeaponBasic
    instance.applyProperties(properties);
    
    // 5. ✅ 保存到 WeaponSchema (已修復!)
    weaponData.setProperties(properties);
    weaponData.quality = quality;
    
    return instance;
}
```

**狀態:** ✅ **已修復** - 現在會同時保存到 WeaponSchema

### 2. WeaponPropertyService.generateWeaponProperties()

**位置:** `src/Game/Services/WeaponPropertyService.ts:60`

```typescript
public generateWeaponProperties(
    weaponId: string,
    quality: WeaponQuality,
    seed: number
): PropertyValue[] {
    const weaponConfig = this.getWeaponConfig(weaponId);
    const properties: PropertyValue[] = [];
    
    // 1. 解析固定屬性
    const fixedProperties = this.parseFixedProperties(weaponConfig.fixedProperties);
    properties.push(...fixedProperties);
    
    // 2. 生成隨機屬性
    const randomProperties = this.generateRandomProperties(
        weaponConfig.randomProperties,
        quality,
        seed
    );
    properties.push(...randomProperties);
    
    return properties;
}
```

**固定屬性解析:**
- 從 `config.fixedProperties` 字串 (如 `"knockback,stun,sweep_angle"`)
- 每個屬性使用**最大值**
- 返回 `PropertyValue[]`

**隨機屬性生成:**
- 從 `config.randomProperties` 字串 (如 `"attackDamage,attackSpeed,criticalChance"`)
- 根據品質決定數量: `normal(0), magic(1), rare(2), epic(3), legendary(4)`
- 使用種子保證一致性
- 在 `min ~ max` 範圍內隨機生成數值

### 3. 品質決定邏輯

**位置:** `src/Game/Managers/WeaponInstanceManager.ts:117`

```typescript
private static determineWeaponQuality(weaponData: WeaponData): WeaponQuality {
    const seed = this.generateSeed(weaponData);
    const seededRandom = this.createSeededRandom(seed);
    
    // 基礎機率
    let baseProbability = seededRandom() * 100;
    
    // 加成計算
    const enhanceBonus = weaponData.enhanceLevel * 2;      // 強化等級
    const levelBonus = (weaponData.level - 1) * 1;        // 武器等級
    
    // 調整機率
    baseProbability -= (enhanceBonus + levelBonus);
    
    // 品質判定
    if (baseProbability < 1) return WeaponQuality.LEGENDARY;
    if (baseProbability < 6) return WeaponQuality.EPIC;
    if (baseProbability < 16) return WeaponQuality.RARE;
    if (baseProbability < 46) return WeaponQuality.MAGIC;
    return WeaponQuality.NORMAL;
}
```

**機率分布:**
- Legendary (傳奇): 1% (0-1)
- Epic (史詩): 5% (1-6)
- Rare (稀有): 10% (6-16)
- Magic (魔法): 30% (16-46)
- Normal (普通): 54% (46-100)

**加成影響:**
- 強化 +10 級 → 機率 -20% → 更容易出高品質
- 武器 Lv.10 → 機率 -9% → 略微提升品質

## ⚠️ 發現的問題

### 問題 1: 掉落系統改變品質後未重新生成屬性 ❌

**位置:** `src/Game/Systems/DropSystem.ts:141`

```typescript
// 生成武器後
const { data: weaponData } = WeaponSystemFacade.createAndGetWeapon(weaponId);

// 調整等級
weaponData.level = weaponLevel;

// ❌ 問題: 改變品質但沒有重新生成屬性!
const desiredQuality = this.rollQualityFromConfig(WEAPON_DROP_CONFIG.qualityRates);
if (desiredQuality !== weaponData.quality) {
    weaponData.quality = desiredQuality;  // 只改了品質
    // ❌ 缺少: 重新生成屬性以匹配新品質
}
```

**後果:**
- 武器顯示為 "Epic" 品質,但只有 1個隨機屬性 (Magic 品質的數量)
- 客戶端看到的品質和實際屬性不符

**修復建議:**
```typescript
if (desiredQuality !== weaponData.quality) {
    weaponData.quality = desiredQuality;
    
    // 重新生成屬性
    const propertyService = WeaponPropertyService.getInstance();
    const seed = WeaponInstanceManager.generateSeed(weaponData);
    const newProperties = propertyService.generateWeaponProperties(
        weaponId,
        desiredQuality,
        seed
    );
    
    weaponData.setProperties(newProperties);
    
    // 清除邏輯實例緩存
    weaponData.invalidateLogicInstance();
}
```

### 問題 2: 撿起武器時沒有恢復 propertiesJson ❌

**位置:** `src/Colyseus/Schema/Item/ServerItem.ts:128`

```typescript
public toWeaponData(): WeaponData | null {
    const weaponData = new WeaponData();
    
    // 複製基本屬性
    weaponData.weaponId = this.itemId;
    weaponData.quality = this.quality;
    weaponData.level = this.level;
    
    // 反序列化武器屬性
    if (this.weaponPropertiesJson) {
        const properties = JSON.parse(this.weaponPropertiesJson);
        
        // ✅ 恢復 uniqueId
        weaponData.uniqueId = properties.uniqueId;
        
        // ✅ 恢復屬性列表
        weaponData.fixedProperties.push(...properties.fixedProperties);
        weaponData.randomProperties.push(...properties.randomProperties);
        
        // ❌ 問題: 沒有恢復 propertiesJson!
        // weaponData.propertiesJson 仍然是 "{}"
    }
    
    return weaponData;
}
```

**後果:**
- 撿起的武器沒有實際屬性值
- 客戶端看到屬性名稱列表,但看不到具體數值
- WeaponBasic 獲取時會重新生成屬性 (可能與原屬性不同!)

**修復建議:**
```typescript
// ServerItem.createFromWeaponData 時保存完整屬性
item.weaponPropertiesJson = JSON.stringify({
    fixedProperties: weaponData.fixedProperties?.toArray() || [],
    randomProperties: weaponData.randomProperties?.toArray() || [],
    uniqueId: weaponData.uniqueId,
    propertiesJson: weaponData.propertiesJson  // ✅ 添加完整屬性值
});

// toWeaponData 時恢復完整屬性
if (properties.propertiesJson) {
    weaponData.propertiesJson = properties.propertiesJson;  // ✅ 恢復屬性值
}
```

### 問題 3: 種子生成依賴 obtainedAt,可能導致屬性變化 ⚠️

**位置:** `src/Game/Managers/WeaponInstanceManager.ts:235`

```typescript
private static generateSeed(weaponData: WeaponData): string {
    return `${weaponData.weaponId}_${weaponData.uniqueId}_${weaponData.obtainedAt}`;
}
```

**潛在風險:**
- 如果 `obtainedAt` 改變 → 種子改變 → 屬性重新生成
- 如果 `uniqueId` 改變 → 種子改變 → 屬性重新生成

**當前狀態:**
- 因為已經在 `createNewInstance` 中保存到 `propertiesJson`,所以不會重新生成
- 但依賴於緩存機制,如果緩存失效仍可能出問題

**建議:**
- 屬性一旦生成,就應該保存到 `propertiesJson`
- 不要每次都依賴種子重新生成

## 📊 數據流向總結

### 創建武器時

```
WeaponConfig (靜態配置)
    ├─> fixedProperties: "knockback,stun"
    └─> randomProperties: "attackDamage,attackSpeed,criticalChance"
         │
         ↓
WeaponPropertyService.generateWeaponProperties()
    ├─> 固定屬性: [knockback: 50, stun: [10,2]]
    └─> 隨機屬性 (根據品質): [attackDamage: 45, attackSpeed: 120]
         │
         ↓
PropertyValue[]
    ├─> 應用到 → WeaponBasic.properties (Map)
    │              └─> 用於戰鬥邏輯
    │
    └─> 保存到 → WeaponSchema.propertiesJson (JSON string)
                   └─> 同步到客戶端
```

### 掉落和撿起時

```
WeaponSchema (背包中)
    └─> propertiesJson: '{"knockback":50,"stun":[10,2],...}'
         │
         ↓ (玩家丟棄)
ServerItem (地圖掉落物)
    └─> weaponPropertiesJson: '{"fixedProperties":[...],"propertiesJson":"..."}'
         │
         ↓ (其他玩家撿起)
WeaponSchema (新玩家背包)
    ├─> ❌ propertiesJson: "{}"  (丟失!)
    └─> ✅ fixedProperties, randomProperties (保留名稱)
```
