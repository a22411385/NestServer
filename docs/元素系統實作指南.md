## 系統概述

### 設計理念

武器元素系統採用**獨立欄位設計**，每把武器擁有一個主元素屬性：

```
武器 = 基礎屬性 + 主元素類型 + 固定屬性 + 隨機屬性
```

### 為什麼選擇獨立欄位？

✅ **與 Debuff 明確關聯**: 每個元素對應特定負面效果  
✅ **天賦系統友好**: 容易判斷和計算元素加成  
✅ **效能優勢**: 直接讀取欄位，無需字串解析  
✅ **UI/UX 清晰**: 武器圖標可顯示元素標記  
✅ **擴展性強**: 未來可添加元素克制系統

## 傷害計算流程

### 1. 基礎傷害計算

```typescript
/**
 * 計算元素傷害
 * @param weapon 武器實例
 * @param target 目標單位
 * @param hero 英雄實例
 * @returns 最終傷害值
 */
public calculateElementalDamage(
    weapon: WeaponSchema, 
    target: ServerGameUnit,
    hero: ServerHero
): number {
    // 1. 基礎傷害
    let damage = weapon.baseDamage + hero.attackDamage;
    
    // 2. 元素傷害加成 (來自天賦系統)
    const elementBonus = hero.getElementDamageBonus(weapon.elementType);
    damage *= (1 + elementBonus / 100);
    
    // 3. 目標元素抗性 (未來擴展)
    // const resistance = target.getElementResistance(weapon.elementType);
    // damage *= (1 - resistance);
    
    // 4. 暴擊計算
    const isCrit = Math.random() * 100 < hero.critRate;
    if (isCrit) {
        damage *= 2.0; // 暴擊傷害倍率
    }
    
    return Math.floor(damage);
}
```

### 2. Debuff 應用流程

```typescript
/**
 * 根據武器元素類型應用對應的 Debuff
 * @param weapon 武器實例
 * @param target 目標單位
 */
public applyElementalDebuff(weapon: WeaponSchema, target: ServerGameUnit): void {
    // 從元素類型映射到 Debuff 類型
    const debuffType = ELEMENT_DEBUFF_MAP[weapon.elementType];
    
    if (!debuffType) return; // 神聖和秘法沒有固定 Debuff
    
    // 檢查武器是否有該 Debuff 屬性
    if (weapon.hasProperty(debuffType)) {
        const debuffProp = weapon.getPropertyValue(debuffType)[0];
        
        // 計算觸發機率
        const roll = Math.random() * 100;
        if (roll < debuffProp.probability) {
            // 添加狀態效果
            target.addStatusEffect({
                type: debuffType,
                duration: debuffProp.duration,
                value: debuffProp.value || debuffProp.intensity,
                sourceId: weapon.uniqueId
            });
            
            console.log(`✅ ${weapon.name} 觸發 ${debuffType} (${debuffProp.probability}%)`);
        }
    }
}
```

### 3. 完整攻擊流程

```typescript
/**
 * 武器攻擊流程 (整合元素系統)
 */
public weaponAttack(weapon: WeaponSchema, hero: ServerHero, target: ServerGameUnit): AttackResult {
    // 1. 計算元素傷害
    const damage = this.calculateElementalDamage(weapon, target, hero);
    
    // 2. 套用傷害
    target.takeDamage(damage, hero);
    
    // 3. 應用元素 Debuff
    this.applyElementalDebuff(weapon, target);
    
    // 4. 其他效果 (擊退、連鎖等)
    this.applyWeaponEffects(weapon, target);
    
    return {
        damage,
        isCrit: false,
        effects: []
    };
}
```

### 天賦系統輔助方法

```typescript
// Hero.ts - 輔助方法

/**
 * 獲取特定元素的傷害加成
 * @returns 傷害加成百分比 (0-100)
 */
public getElementDamageBonus(elementType: string): number {
    switch (elementType) {
        case 'physical': return this.physicalDamageBonus;
        case 'fire': return this.fireDamageBonus;
        case 'ice': return this.iceDamageBonus;
        case 'lightning': return this.lightningDamageBonus;
        case 'poison': return this.poisonDamageBonus;
        case 'holy': return this.holyDamageBonus;
        case 'shadow': return this.shadowDamageBonus;
        case 'arcane': return this.arcaneDamageBonus;
        default: return 0;
    }
}

/**
 * 設置特定元素的傷害加成
 */
public setElementDamageBonus(elementType: string, bonus: number): void {
    switch (elementType) {
        case 'physical': this.physicalDamageBonus = bonus; break;
        case 'fire': this.fireDamageBonus = bonus; break;
        case 'ice': this.iceDamageBonus = bonus; break;
        case 'lightning': this.lightningDamageBonus = bonus; break;
        case 'poison': this.poisonDamageBonus = bonus; break;
        case 'holy': this.holyDamageBonus = bonus; break;
        case 'shadow': this.shadowDamageBonus = bonus; break;
        case 'arcane': this.arcaneDamageBonus = bonus; break;
    }
}

/**
 * 增加特定元素的傷害加成 (累加)
 */
public addElementDamageBonus(elementType: string, bonus: number): void {
    const currentBonus = this.getElementDamageBonus(elementType);
    this.setElementDamageBonus(elementType, currentBonus + bonus);
}
```

## Debuff 關聯系統

### 元素到 Debuff 映射表

```typescript
// WeaponPropertyTypes.ts
export const ELEMENT_DEBUFF_MAP: Record<ElementTypeValue, PropertyTypeValue | null> = {
    [ElementType.PHYSICAL]: PropertyType.BLEED,      // 物理 → 流血
    [ElementType.FIRE]: PropertyType.BURN,           // 火 → 燃燒
    [ElementType.ICE]: PropertyType.FREEZE,          // 冰 → 冰凍
    [ElementType.LIGHTNING]: PropertyType.STUN,      // 電 → 眩暈
    [ElementType.POISON]: PropertyType.POISON,       // 毒 → 中毒
    [ElementType.HOLY]: null,                        // 神聖 → 無負面效果
    [ElementType.SHADOW]: PropertyType.SLOW,         // 暗影 → 緩速
    [ElementType.ARCANE]: null                       // 秘法 → 無固定效果
};
```

### Debuff 到元素反向映射

```typescript
// WeaponPropertyTypes.ts
export const DEBUFF_TO_ELEMENT_MAP: Record<string, ElementTypeValue> = {
    [PropertyType.BLEED]: ElementType.PHYSICAL,
    [PropertyType.BURN]: ElementType.FIRE,
    [PropertyType.FREEZE]: ElementType.ICE,
    [PropertyType.STUN]: ElementType.LIGHTNING,
    [PropertyType.POISON]: ElementType.POISON,
    [PropertyType.SLOW]: ElementType.SHADOW
};
```

### 使用場景

```typescript
/**
 * 範例 1: 根據元素類型判斷應該施加的 Debuff
 */
const element = weapon.elementType; // 'fire'
const debuff = ELEMENT_DEBUFF_MAP[element]; // 'burn'

/**
 * 範例 2: 根據 Debuff 類型判斷其元素屬性 (用於天賦系統)
 */
const debuffType = 'burn';
const element = DEBUFF_TO_ELEMENT_MAP[debuffType]; // 'fire'
const bonus = hero.getElementDamageBonus(element); // 取得火系加成

/**
 * 範例 3: 天賦 - "火系 Debuff 持續時間 +50%"
 */
if (DEBUFF_TO_ELEMENT_MAP[debuff.type] === 'fire') {
    debuff.duration *= 1.5;
}
```

## 常見問題

### Q1: 武器可以有多個元素嗎？

**A**: 目前設計是一把武器一個主元素，但可以通過 `fixedProperties` 添加額外元素傷害加成。

範例:
```
主元素: fire
固定屬性: burn, ice_damage_bonus
```

### Q2: 神聖和秘法為什麼沒有 Debuff？

**A**: 
- 神聖適合治療/輔助職業，可以施加 Buff 而非 Debuff
- 秘法代表萬能魔法，可以根據情況施加不同效果

### Q3: 如何添加新元素？

**A**: 
1. 在 `ElementType` 常數中添加新元素
2. 更新 `ELEMENT_DEBUFF_MAP` 映射
3. 在 `Hero.ts` 添加對應的加成屬性
4. 更新 `getElementDamageBonus()` 方法

### Q4: 元素系統會影響效能嗎？

**A**: 不會。使用直接欄位讀取，比字串解析更快。
