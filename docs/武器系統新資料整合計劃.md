# 武器系統新資料整合實施計劃

## 📋 概述

本文檔詳細說明如何將新的三表架構（StatusEffectDefinitions、WeaponModifiers、AttributeBonus）整合到現有武器系統中。

---

## 🎯 目標

1. **WeaponConfig** 支援配置三種屬性
2. **WeaponPropertyService** 載入並解析三種屬性
3. **WeaponSchema** 儲存三種屬性（同步到客戶端）
4. **WeaponDataService** 計算時考慮武器詞綴
5. **Hero** 應用屬性加成到角色
6. **客戶端** 獲得統一的顯示資料

---

### 2️⃣ WeaponPropertyService.ts

**位置**: `src/Game/Services/WeaponPropertyService.ts`

**更改**: 載入三個表，擴展解析方法

```typescript
export class WeaponPropertyService {
    private isInitialized: boolean = false;
    
    // 🆕 三個 Map 分別儲存
    private statusEffects: Map<string, StatusEffectDefinition> = new Map();
    private weaponModifiers: Map<string, WeaponModifier> = new Map();
    private attributeBonuses: Map<string, AttributeBonus> = new Map();
    
    /**
     * 🆕 初始化時載入三個表
     */
    public async initialize(): Promise<void> {
        if (this.isInitialized) {
            console.log('⚠️ WeaponPropertyService 已初始化');
            return;
        }

        try {
            // 載入狀態效果定義
            const statusEffectList = ConfigManager.getAll<StatusEffectDefinition>('StatusEffectDefinitions');
            for (const effect of statusEffectList) {
                this.statusEffects.set(effect.id, effect);
            }

            // 🆕 載入武器詞綴定義
            const modifierList = ConfigManager.getAll<WeaponModifier>('WeaponModifiers');
            for (const modifier of modifierList) {
                this.weaponModifiers.set(modifier.id, modifier);
            }

            // 🆕 載入屬性加成定義
            const bonusList = ConfigManager.getAll<AttributeBonus>('AttributeBonus');
            for (const bonus of bonusList) {
                this.attributeBonuses.set(bonus.id, bonus);
            }

            this.isInitialized = true;
            console.log(`✅ WeaponPropertyService 初始化完成`);
            console.log(`   - 狀態效果: ${statusEffectList.length} 個`);
            console.log(`   - 武器詞綴: ${modifierList.length} 個`);
            console.log(`   - 屬性加成: ${bonusList.length} 個`);

        } catch (error) {
            console.error('❌ WeaponPropertyService 初始化失敗:', error);
            throw error;
        }
    }

    /**
     * 🆕 擴展返回類型
     */
    public generateWeaponProperties(
        weaponId: string,
        quality: WeaponQuality
    ): {
        statusEffects: PropertyValue[],
        modifiers: WeaponModifier[],
        bonuses: AttributeBonus[]
    } {
        if (!this.isInitialized) {
            throw new Error('WeaponPropertyService 未初始化');
        }

        try {
            const weaponConfig = ConfigManager.getById<WeaponConfigDefinition>('WeaponConfigs', weaponId);
            if (!weaponConfig) {
                console.warn(`⚠️ 找不到武器配置: ${weaponId}`);
                return { statusEffects: [], modifiers: [], bonuses: [] };
            }

            // 1. 解析狀態效果（現有邏輯）
            const statusEffects = this.parseFixedProperties(weaponConfig.fixedProperties, quality);

            // 2. 🆕 解析武器詞綴
            const modifiers = this.parseFixedModifiers(weaponConfig.fixedModifiers || '');

            // 3. 🆕 解析屬性加成
            const bonuses = this.parseFixedBonuses(weaponConfig.fixedBonuses || '');

            console.log(`🎲 ${weaponId} (${quality}) 生成了:`);
            console.log(`   - 狀態效果: ${statusEffects.length} 個`);
            console.log(`   - 武器詞綴: ${modifiers.length} 個`);
            console.log(`   - 屬性加成: ${bonuses.length} 個`);

            return { statusEffects, modifiers, bonuses };

        } catch (error) {
            console.error(`❌ 生成武器屬性失敗 ${weaponId}:`, error);
            return { statusEffects: [], modifiers: [], bonuses: [] };
        }
    }

    /**
     * 🆕 解析武器詞綴字串
     * @param fixedModsString "piercing,chain_attack,critical_chance"
     */
    private parseFixedModifiers(fixedModsString: string): WeaponModifier[] {
        if (!fixedModsString) return [];

        const modIds = fixedModsString.split(',').map(s => s.trim());
        const modifiers: WeaponModifier[] = [];

        for (const modId of modIds) {
            const modifierDef = this.weaponModifiers.get(modId);
            if (!modifierDef) {
                console.warn(`⚠️ 未知的武器詞綴: ${modId}`);
                continue;
            }

            if (!modifierDef.enabled) {
                console.log(`⏸️ 武器詞綴已停用: ${modId}`);
                continue;
            }

            modifiers.push(modifierDef);
        }

        return modifiers;
    }

    /**
     * 🆕 解析屬性加成字串
     * @param fixedBonusString "strength,attack_speed"
     */
    private parseFixedBonuses(fixedBonusString: string): AttributeBonus[] {
        if (!fixedBonusString) return [];

        const bonusIds = fixedBonusString.split(',').map(s => s.trim());
        const bonuses: AttributeBonus[] = [];

        for (const bonusId of bonusIds) {
            const bonusDef = this.attributeBonuses.get(bonusId);
            if (!bonusDef) {
                console.warn(`⚠️ 未知的屬性加成: ${bonusId}`);
                continue;
            }

            if (!bonusDef.enabled) {
                console.log(`⏸️ 屬性加成已停用: ${bonusId}`);
                continue;
            }

            bonuses.push(bonusDef);
        }

        return bonuses;
    }

    // ... 保留現有的 parseFixedProperties() 方法
}
```

export class WeaponSchema extends Schema {

        modifiers: WeaponModifier[],
        bonuses: AttributeBonus[]

        // 1. 狀態效果（保留現有邏輯）

            this.updateBaseStats(effect);

        this.modifiers = data.modifiers;

        // 3. 🆕 屬性加成（直接儲存）

        console.log(`✅ 武器屬性已應用:`);

        console.log(`   - 武器詞綴: ${this.modifiers.length} 個`);
        console.log(`   - 屬性加成: ${this.bonuses.length} 個`);
    }

     * 🆕 獲取武器詞綴

        return this.modifiers || [];

    /**
     * 🆕 獲取屬性加成

### 5️⃣ WeaponDataService.ts

**位置**: `src/Game/Services/WeaponDataService.ts`

**更改**: 計算最終屬性時考慮武器詞綴

```typescript
export class WeaponDataService {
    /**
     * 🆕 修改器屬性映射表
     */
    private static readonly MODIFIER_STAT_MAP: Record<string, keyof FinalWeaponStats> = {
        'critical_chance': 'finalCritRate',
        'critical_damage': 'finalCritDamage',
        'pierce_count': 'pierceCount',
        'chain_count': 'chainCount',
        'bounce_count': 'bounceCount',
        'projectile_speed': 'projectileSpeed',
        // ... 其他映射
    };

    static calculateFinalStats(weaponData: WeaponSchema): FinalWeaponStats {
        const config = WeaponConfigManager.getConfig(weaponData.weaponId);
        if (!config) {
            throw new Error(`無法找到武器配置: ${weaponData.weaponId}`);
        }

        // 計算基礎屬性
        const multipliers = this.calculateMultipliers(weaponData);
        const baseStats: FinalWeaponStats = {
            finalDamage: Math.floor(config.baseDamage * multipliers.damage),
            finalRange: Math.floor(config.attackRange + multipliers.range),
            finalSpeed: Math.max(100, Math.floor(config.attackSpeed * multipliers.speed)),
            finalCritRate: this.calculateBaseCritRate(weaponData) * multipliers.stats,
            finalCritDamage: this.calculateBaseCritDamage(weaponData),
            finalLifeSteal: this.calculateBaseLifeSteal(weaponData),
            displayName: config.displayName || config.name,
            rarity: weaponData.rarity,
            pierceCount: 0,      // 🆕 預設值
            chainCount: 0,       // 🆕 預設值
            bounceCount: 0,      // 🆕 預設值
            projectileSpeed: 1,  // 🆕 預設值
        };

        // 🆕 應用武器詞綴
        this.applyWeaponModifiers(baseStats, weaponData.getModifiers());

        return baseStats;
    }

    /**
     * 🆕 應用武器詞綴到最終屬性
     * 遵循 POE 規則：FLAT → INCREASED → MORE
     */
    private static applyWeaponModifiers(
        baseStats: FinalWeaponStats,
        modifiers: WeaponModifier[]
    ): void {
        if (modifiers.length === 0) return;

        // 分類修改器
        const flatMods = modifiers.filter(m => m.modifierType === 'flat');
        const increasedMods = modifiers.filter(m => m.modifierType === 'increased');
        const moreMods = modifiers.filter(m => m.modifierType === 'more');

        // 1. 應用 FLAT（加法）
        flatMods.forEach(mod => {
            const statKey = this.MODIFIER_STAT_MAP[mod.affectedStat];
            if (statKey && statKey in baseStats) {
                const currentValue = baseStats[statKey] as number || 0;
                (baseStats as any)[statKey] = currentValue + mod.baseValue;
            }
        });

        // 2. 應用 INCREASED（加法後一起乘）
        const increasedTotal: Record<string, number> = {};
        increasedMods.forEach(mod => {
            const statKey = this.MODIFIER_STAT_MAP[mod.affectedStat];
            if (statKey) {
                increasedTotal[statKey] = (increasedTotal[statKey] || 0) + mod.baseValue;
            }
        });
        Object.entries(increasedTotal).forEach(([statKey, totalIncrease]) => {
            if (statKey in baseStats) {
                const currentValue = (baseStats as any)[statKey] as number || 0;
                (baseStats as any)[statKey] = currentValue * (1 + totalIncrease / 100);
            }
        });

        // 3. 應用 MORE（乘法，連乘）
        moreMods.forEach(mod => {
            const statKey = this.MODIFIER_STAT_MAP[mod.affectedStat];
            if (statKey && statKey in baseStats) {
                const currentValue = (baseStats as any)[statKey] as number || 0;
                (baseStats as any)[statKey] = currentValue * (1 + mod.baseValue / 100);
            }
        });

        console.log(`🔧 已應用 ${modifiers.length} 個武器詞綴`);
    }
}
```

**⚠️ 注意**: FinalWeaponStats 介面需要擴展以包含新的屬性（pierceCount, chainCount 等）。

## ⚠️ 注意事項

### Schema 同步問題

**問題**: `WeaponModifier` 和 `AttributeBonus` 不是 Schema 類，無法直接同步。

**解決方案 A**: 將它們轉換為 Schema 類

```typescript
// 建立新的 Schema 類
export class WeaponModifierSchema extends Schema {
    @type("string") id: string;
    @type("string") displayName: string;
    @type("number") baseValue: number;
    // ... 其他欄位
}

// 在 WeaponSchema 中使用
@type([WeaponModifierSchema]) modifiers = new ArraySchema<WeaponModifierSchema>();
```

**解決方案 B**: 使用 JSON 字串序列化（簡單但不夠類型安全）

```typescript
@type("string") modifiersJson: string = "[]";

public getModifiers(): WeaponModifier[] {
    return JSON.parse(this.modifiersJson || "[]");
}

public setModifiers(modifiers: WeaponModifier[]): void {
    this.modifiersJson = JSON.stringify(modifiers);
}
```

**推薦**: 方案 B（簡單快速），未來再優化為方案 A。

### 修改器計算順序

確保遵循 POE 規則：

1. **FLAT** - 固定值加法
2. **INCREASED** - 百分比加法（多個 INCREASED 相加後一起乘）
3. **MORE** - 百分比乘法（每個 MORE 獨立相乘）

**範例計算**:
```
基礎攻擊力 = 100
+ FLAT +20 = 120
+ INCREASED 30% + INCREASED 20% = 120 × (1 + 0.3 + 0.2) = 180
× MORE 50% = 180 × 1.5 = 270
× MORE 20% = 270 × 1.2 = 324
```
