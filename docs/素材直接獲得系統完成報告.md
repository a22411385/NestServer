### 2. 掉落系統重構 (服務端)

#### DropSystem.ts 更新
**檔案位置:** `NestServer/src/Game/Systems/Items/DropSystem.ts`

**核心改動:**

```typescript
/**
 * 🎯 處理敵人死亡掉落 - 直接給擊殺者獎勵
 */
public handleEnemyDeath(enemy: ServerEnemy, killer: ServerGameUnit): void {
    // 只有玩家角色才獲得獎勵
    if (!(killer instanceof ServerHero)) return;

    const hero = killer as ServerHero;
    
    // 1. 給予金幣
    hero.gold += this.calculateGoldDrop(enemy, hero);
    
    // 2. 給予經驗值
    hero.addExperience(this.calculateExpDrop(enemy, hero));
    
    // 3. 掉落素材 (直接加入玩家素材庫)
    this.dropMaterialsToPlayer(enemy, hero);
}
```

**新增方法 - dropMaterialsToPlayer:**
```typescript
private dropMaterialsToPlayer(enemy: ServerEnemy, hero: ServerHero): void {
    const enemyLevel = enemy.lv || 1;
    
    // 獲取該等級可掉落的素材列表
    const availableMaterials = ConfigManager.getMaterialsByEnemyLevel(enemyLevel);
    
    for (const materialConfig of availableMaterials) {
        // 機率判定
        const dropChance = Math.random() * 100;
        if (dropChance <= materialConfig.baseDropRate) {
            // 隨機數量
            const quantity = Math.floor(
                Math.random() * (materialConfig.maxDropQuantity - materialConfig.minDropQuantity + 1)
            ) + materialConfig.minDropQuantity;
            
            // 直接加入素材庫 (使用 MapSchema)
            const currentQuantity = hero.materials.get(materialConfig.id) || 0;
            const newQuantity = currentQuantity + quantity;
            
            // 檢查堆疊上限
            if (newQuantity <= materialConfig.stackSize) {
                hero.materials.set(materialConfig.id, newQuantity);
            } else {
                hero.materials.set(materialConfig.id, materialConfig.stackSize);
            }
        }
    }
}
```

```typescript
const materialsListener = $(unit).materials.onChange((item, key) => {
    // 只有我自己的角色才顯示通知
    if (unit.owner === useGameCoreStore().sessionId) {
        import('@/stores/notification').then(({ useNotificationStore }) => {
            const notificationStore = useNotificationStore();
            
            import('@/Types/MaterialTypes').then(({ MATERIAL_CONFIGS }) => {
                const config = MATERIAL_CONFIGS[key];
                const gained = item.value - (oldValue || 0);
                
                if (gained > 0) {
                    notificationStore.showMaterialGained(
                        config.name,
                        gained,
                        config.icon || '⚒️'
                    );
                }
            });
        });
    }
});
```

## 🎯 優勢分析

### 之前的系統 (掉落到地圖)

❌ **缺點:**
1. 玩家需要停下來撿取物品
2. 戰鬥節奏被打斷
3. 多人遊戲時需要搶奪掉落
4. 地圖上累積大量物品影響性能
5. 掉落物可能被遺漏

### 現在的系統 (直接給予)

✅ **優點:**
1. 流暢的戰鬥體驗,無需停頓
2. 即時回饋,成就感更強
3. 公平分配,各自獲得獎勵
4. 減少地圖物體數量,提升性能
5. 右上角通知讓玩家不錯過任何獎勵

## 🔧 使用範例

### 顯示自定義通知

```typescript
import { useNotificationStore } from '@/stores/notification'

const notification = useNotificationStore()

// 顯示素材獲得
notification.showMaterialGained('火焰精華', 5, '🔥')

// 顯示金幣獲得
notification.showGoldGained(250)

// 顯示物品獲得
notification.showItemGained('生命藥水', 3, '🧪')

// 顯示成功訊息
notification.showSuccess('裝備成功!', '武器裝備')

// 顯示錯誤訊息
notification.showError('背包已滿', '無法拾取')

// 清除所有通知
notification.clearAll()
```

### 在組件中使用

```vue
<script setup lang="ts">
import { useNotificationStore } from '@/stores/notification'

const notification = useNotificationStore()

const onCraft = () => {
  try {
    // 製作武器邏輯

    // 顯示錯誤通知
    notification.showError('材料不足', '製作失敗')
  }
}
```
