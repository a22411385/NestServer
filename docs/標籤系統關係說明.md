## Parent 層級關係

### 📊 概念說明

`parent` 欄位用於建立標籤之間的**父子層級關係**，類似樹狀結構。

```
              elemental (元素通用)
                   |
        +----------+----------+----------+
        |          |          |          |
      fire       cold    lightning    poison
    (火元素)   (冰元素)  (雷電元素)  (毒元素)
        |          |          |          |
      burn      freeze      shock      poison_debuff
    (燃燒)     (冰凍)      (電擊)      (中毒效果)
```

### 🎯 為什麼需要 Parent？

#### 1️⃣ 語意分類
標籤可以形成清晰的分類層級：

```
weapon (武器通用標籤)
├── sword (劍)
├── bow (弓)
└── staff (法杖)
```

#### 2️⃣ 繼承查詢
當查詢 `fire` 標籤時，可以自動包含所有子標籤：

```typescript
// 查詢所有火元素相關的屬性
// 會同時匹配擁有 fire 或 burn 標籤的屬性
const fireProperties = findPropertiesByTag('fire', { includeChildren: true });
// 返回: [burn_property, fire_sword_property, ...]
```

#### 3️⃣ 反向追溯
從子標籤可以追溯到父標籤：

```typescript
// burn 標籤的完整路徑
getTagPath('burn');
// 返回: ['elemental', 'fire', 'burn']
```

### 📝 CSV 範例

```csv
id,displayName,description,category,parent,enabled
elemental,元素,通用元素標籤,category,,TRUE
fire,火元素,火元素相關效果和傷害,element,elemental,TRUE
burn,燃燒,持續火焰傷害,ailment,fire,TRUE
```

**關係解讀**：
- `elemental`: 沒有 parent（頂層標籤）
- `fire`: parent 是 `elemental`（火是元素的一種）
- `burn`: parent 是 `fire`（燃燒是火元素造成的異常狀態）

### ⚠️ Parent 使用規則

#### ✅ 正確用法

```csv
# 正確：建立清晰的層級關係
id,parent
weapon,
sword,weapon
fire_sword,sword
```

#### ❌ 錯誤用法

```csv
# 錯誤 1：循環引用
id,parent
fire,burn
burn,fire

# 錯誤 2：層級過深（超過 3 層）
id,parent
a,
b,a
c,b
d,c
e,d  # 太深了！

# 錯誤 3：parent 不存在
id,parent
burn,fire_element  # fire_element 標籤不存在
```

## WeaponPropertyDefinition 與 TagDefinition 的關係

### 📊 概念說明

**TagDefinition（標籤定義表）** 和 **WeaponPropertyDefinition（武器屬性定義表）** 是**一對多**的關係：

```
TagDefinition (標籤定義)
    ↓ 被引用
WeaponPropertyDefinition (屬性定義)
```

### 🎯 關係圖解

```
┌─────────────────────────────────────┐
│     TagDefinition (標籤定義表)        │
│  ┌───────────────────────────────┐  │
│  │ id: fire                      │  │
│  │ displayName: 火元素           │  │
│  │ category: element             │  │
│  │ color: #FF4500                │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
              ↓ 被引用
┌─────────────────────────────────────┐
│ WeaponPropertyDefinition (屬性定義) │
│  ┌───────────────────────────────┐  │
│  │ id: burn                      │  │
│  │ displayName: 燃燒             │  │
│  │ tags: "fire,ailment,debuff"   │◄─ 引用 TagDefinition
│  │ baseProbability: 30           │  │
│  │ baseDamage: 10                │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 📝 具體範例

#### TagDefinition (標籤定義表)

```csv
id,displayName,description,category,color,parent,enabled
fire,火元素,火元素相關效果和傷害,element,#FF4500,,TRUE
ailment,異常狀態,造成異常狀態效果,ailment,#DC143C,,TRUE
debuff,減益,負面效果,function,#FF0000,,TRUE
damage,傷害,增加傷害,function,#DC143C,,TRUE
```

#### WeaponPropertyDefinition (屬性定義表)

```csv
id,displayName,tags,baseProbability,baseDamage,category
burn,燃燒,"fire,ailment,debuff,damage",30,10,debuff
```

**關係說明**：
- `burn` 屬性的 `tags` 欄位包含：`fire,ailment,debuff,damage`
- 這四個標籤 (`fire`, `ailment`, `debuff`, `damage`) 必須在 `TagDefinition` 表中有定義
- 系統會根據 `TagDefinition` 讀取標籤的元數據（顏色、圖示、描述等）

### 🔍 驗證機制

#### 1️⃣ 標籤合法性驗證

確保屬性使用的標籤都存在於 `TagDefinition` 中：

```typescript
function validatePropertyTags(
    property: WeaponPropertyDefinition,
    validTags: TagDefinition[]
): boolean {
    // 解析屬性的標籤字串
    const propertyTags = property.tags.split(',').map(t => t.trim());
    
    // 獲取所有已啟用的標籤 ID
    const validTagIds = validTags
        .filter(t => t.enabled)
        .map(t => t.id);
    
    // 檢查每個標籤是否都存在
    const invalidTags = propertyTags.filter(tag => !validTagIds.includes(tag));
    
    if (invalidTags.length > 0) {
        console.error(`❌ 屬性 ${property.id} 使用了無效標籤: ${invalidTags.join(', ')}`);
        return false;
    }
    
    return true;
}

// 使用範例
const burnProperty = { id: 'burn', tags: 'fire,ailment,debuff,damage', ... };
const tagDefinitions = loadTagDefinitions(); // 從 Google Sheets 載入

if (validatePropertyTags(burnProperty, tagDefinitions)) {
    console.log('✅ 標籤驗證通過');
}
```

#### 2️⃣ 標籤啟用狀態檢查

```typescript
function checkDisabledTags(
    property: WeaponPropertyDefinition,
    tagDefinitions: TagDefinition[]
): string[] {
    const propertyTags = property.tags.split(',').map(t => t.trim());
    const tagMap = new Map(tagDefinitions.map(t => [t.id, t]));
    
    // 找出已停用的標籤
    const disabledTags = propertyTags.filter(tagId => {
        const tag = tagMap.get(tagId);
        return tag && !tag.enabled;
    });
    
    return disabledTags;
}
```

天賦可以影響擁有特定標籤的屬性：

```typescript

const talentEffect = {
    stat: 'damage',

// burn 屬性的標籤包含 fire
const burnProperty = {
    id: 'burn',
    tags: 'fire,ailment,debuff,damage',

// 系統會自動應用天賦加成
if (TagMatcher.hasTag(burnProperty.tags, 'fire')) {
    burnProperty.baseDamage *= 1.2; // 10 * 1.2 = 12
}
```

### 場景 2: 元素傷害計算

根據標籤計算元素傷害加成：

```typescript
class Hero {
    // 獲取特定標籤的傷害加成
    getTagDamageBonus(tags: string[]): number {
        let bonus = 0;
        
        // 檢查是否有火元素標籤
        if (tags.includes('fire')) {
            bonus += this.fireDamageBonus;
        }
        
        // 檢查是否有異常狀態標籤
        if (tags.includes('ailment')) {
            bonus += this.ailmentDamageBonus;
        }
        
        return bonus;
    }
}

// 使用範例

```

function renderPropertyTag(
    property: WeaponPropertyDefinition,
    tagDefinitions: TagDefinition[]
) {
    const propertyTags = property.tags.split(',').map(t => t.trim());
    const tagMap = new Map(tagDefinitions.map(t => [t.id, t]));
    
    return propertyTags.map(tagId => {

        return {

            color: tag.color || '#CCCCCC',

### 場景 4: 智能搜尋

使用 parent 關係進行智能搜尋：

```typescript
// 搜尋所有火元素相關的屬性
function findPropertiesByTagFamily(
    baseTag: string,
    properties: WeaponPropertyDefinition[],
    tagDefinitions: TagDefinition[]
): WeaponPropertyDefinition[] {
    // 1. 找出 baseTag 的所有子標籤
    const childTags = findChildTags(baseTag, tagDefinitions);
    const allRelatedTags = [baseTag, ...childTags];
    
    // 2. 篩選包含任一相關標籤的屬性
    return properties.filter(prop => {
        const propTags = prop.tags.split(',').map(t => t.trim());
        return propTags.some(tag => allRelatedTags.includes(tag));
    });
}

function findChildTags(parentId: string, tagDefinitions: TagDefinition[]): string[] {
    return tagDefinitions
        .filter(t => t.parent === parentId)
        .map(t => t.id);
}

// 使用範例
const fireProperties = findPropertiesByTagFamily('fire', allProperties, tagDefinitions);
// 返回所有包含 fire 或 burn 標籤的屬性
```

## 程式碼範例

### 完整載入和驗證流程

```typescript
import { GoogleSheetCache } from '@/Tasks/GoogleSheetCache';
import { TagDefinition, WeaponPropertyDefinition } from '@/Types/Equipment/WeaponPropertyTypes';

class PropertyManager {
    private tagDefinitions: TagDefinition[] = [];
    private propertyDefinitions: WeaponPropertyDefinition[] = [];

    async initialize() {
        // 1. 載入 Google Sheets 資料
        const cache = GoogleSheetCache.getInstance();
        await cache.init();
        const data = cache.getData();

        if (!data) {
            throw new Error('Failed to load cache data');
        }

        // 2. 載入標籤定義
        this.tagDefinitions = data.TagDefinitions || [];
        console.log(`✅ 載入 ${this.tagDefinitions.length} 個標籤定義`);

        // 3. 載入屬性定義
        this.propertyDefinitions = data.WeaponProperties || [];
        console.log(`✅ 載入 ${this.propertyDefinitions.length} 個屬性定義`);

        // 4. 驗證所有屬性的標籤
        this.validateAllProperties();
    }

    private validateAllProperties() {
        const validTagIds = this.tagDefinitions
            .filter(t => t.enabled)
            .map(t => t.id);

        let validCount = 0;
        let invalidCount = 0;

        for (const property of this.propertyDefinitions) {
            const propertyTags = property.tags.split(',').map(t => t.trim());
            const invalidTags = propertyTags.filter(tag => !validTagIds.includes(tag));

            if (invalidTags.length > 0) {
                console.error(
                    `❌ 屬性 ${property.id} (${property.displayName}) 使用了無效標籤: ${invalidTags.join(', ')}`
                );
                invalidCount++;
            } else {
                validCount++;
            }
        }

        console.log(`\n📊 標籤驗證結果:`);
        console.log(`   ✅ 有效: ${validCount} 個屬性`);
        console.log(`   ❌ 無效: ${invalidCount} 個屬性`);
    }

    // 根據標籤查詢屬性
    findPropertiesByTag(tagId: string, includeChildren: boolean = false): WeaponPropertyDefinition[] {
        let targetTags = [tagId];

        if (includeChildren) {
            // 包含所有子標籤
            const childTags = this.tagDefinitions
                .filter(t => t.parent === tagId)
                .map(t => t.id);
            targetTags = [...targetTags, ...childTags];
        }

        return this.propertyDefinitions.filter(prop => {
            const propTags = prop.tags.split(',').map(t => t.trim());
            return targetTags.some(tag => propTags.includes(tag));
        });
    }

    // 獲取標籤的完整路徑
    getTagPath(tagId: string): string[] {
        const path: string[] = [tagId];
        let currentTag = this.tagDefinitions.find(t => t.id === tagId);

        while (currentTag?.parent) {
            path.unshift(currentTag.parent);
            currentTag = this.tagDefinitions.find(t => t.id === currentTag!.parent);
        }

        return path;
    }

    // 獲取標籤顯示資訊
    getTagDisplay(tagId: string): { name: string; color: string; icon: string } | null {
        const tag = this.tagDefinitions.find(t => t.id === tagId);
        if (!tag) return null;

        return {
            name: tag.displayName,
            color: tag.color || '#CCCCCC',
            icon: tag.icon || 'default'
        };
    }
}

// 使用範例
const manager = new PropertyManager();
await manager.initialize();

// 查詢所有火元素屬性（包含子標籤）
const fireProperties = manager.findPropertiesByTag('fire', true);
console.log('🔥 火元素屬性:', fireProperties.map(p => p.displayName));

// 獲取 burn 標籤的完整路徑
const burnPath = manager.getTagPath('burn');
console.log('🏷️ burn 標籤路徑:', burnPath); // ['elemental', 'fire', 'burn']

// 獲取標籤顯示資訊
const fireDisplay = manager.getTagDisplay('fire');
console.log('🎨 fire 標籤顯示:', fireDisplay);
// { name: '火元素', color: '#FF4500', icon: 'flame' }
```

## 常見問題

### Q1: 為什麼不直接在 WeaponPropertyDefinition 中儲存標籤的完整資訊？

**A**: 分離設計的優勢：
- ✅ **避免重複**: 多個屬性可能使用相同標籤，集中管理避免資料重複
- ✅ **易於維護**: 修改標籤顏色/圖示時只需更新一處
- ✅ **資料一致性**: 確保所有使用該標籤的屬性資訊一致
- ✅ **擴展性**: 未來可以為標籤添加更多元數據

### Q2: parent 可以有多個嗎？

**A**: 不行。每個標籤只能有**一個** parent（單繼承）。
- ❌ 錯誤: `burn` 的 parent 是 `fire,elemental`
- ✅ 正確: `burn` 的 parent 是 `fire`，`fire` 的 parent 是 `elemental`

### Q3: WeaponPropertyDefinition 的 tags 欄位可以是空的嗎？

**A**: 理論上可以，但不建議：
```typescript
// 可以編譯，但沒有標籤會導致無法匹配任何效果
const property = {
    id: 'mystery',
    tags: '', // 空字串
    ...
};
```

建議至少包含一個分類標籤（如 `attribute`, `combat`, `debuff`）。

### Q4: 如何處理同義標籤（如 ice 和 cold）？

**A**: 使用 parent 關係處理：

```csv
id,displayName,parent
cold,冰元素,elemental
ice,冰元素,cold
```

或者在程式碼中建立映射：

```typescript
const tagAliases = {
    'ice': 'cold',
    'lightning': 'thunder'
};

function normalizeTag(tag: string): string {
    return tagAliases[tag] || tag;
}
```

### Q5: 標籤太多會影響效能嗎？

**A**: 影響很小：
- 標籤定義只在啟動時載入一次
- 標籤匹配使用 `Set` 或 `Map` 結構，O(1) 查詢
- 建議標籤數量控制在 100 個以內

### Q6: 可以動態新增標籤嗎？

**A**: 可以，但需要：
1. 在 Google Sheets 的 `TagDefinitions` 表中新增
2. 重新載入快取
3. 驗證所有使用該標籤的屬性

```typescript
await cache.updateCache();
await propertyManager.initialize();
```

## 總結

### 📝 核心概念

1. **TagDefinition.parent**: 建立標籤之間的層級關係（樹狀結構）
2. **WeaponPropertyDefinition.tags**: 引用多個 TagDefinition（一對多關係）

### 🎯 關係圖

```
TagDefinition (標籤定義)
    ├─ parent 關係: 標籤之間的層級（火 → 燃燒）
    └─ 被引用關係: 屬性使用標籤（燃燒屬性 → fire 標籤）

WeaponPropertyDefinition (屬性定義)
    └─ tags 欄位: 引用多個標籤（"fire,ailment,debuff"）
```

### ✅ 最佳實踐

1. **標籤定義**: 先設計完整的標籤系統
2. **驗證機制**: 確保屬性使用的標籤都存在
3. **層級設計**: 控制在 2-3 層，避免過深
4. **命名規範**: 保持一致的命名風格
