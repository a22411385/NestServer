### 問題 1: `generateStatusEffects()` 方法缺失 ✅ 已修復

**位置**: `WeaponBasic.ts`

**問題描述**:
- 子類 `MeleeWeapon` 和 `ProjectileWeapon` 在 `tryAttack()` 中調用 `this.generateStatusEffects()`
- 但父類 `WeaponBasic` 中沒有實現此方法

**修復內容**:
在 `WeaponBasic.ts` 中添加了完整的實現：

```typescript
/**
 * 🆕 從屬性系統生成狀態效果配置
 * 將 PropertyValue[] 轉換為 StatusEffectConfig[]
 */
protected generateStatusEffects(): StatusEffectConfig[] {
    const allProperties = this.getAllProperties();
    const statusEffects: StatusEffectConfig[] = [];

    for (const prop of allProperties) {
      // 只處理 debuff/buff 類別的屬性
      if (prop.category !== 'debuff' && prop.category !== 'buff') {
        continue;
      }

      // 只包含有機率觸發的效果
      if (prop.probability > 0) {
        statusEffects.push({
          type: prop.id,                    // 使用屬性ID
          duration: prop.duration * 1000,   // 秒 → 毫秒
          value: prop.value,                // 效果數值
          chance: prop.probability,         // 觸發機率 (0-100)
          category: prop.category,          // 類別
        });
      }
    }

    return statusEffects;
}
```

**轉換邏輯**:
| PropertyValue | → | StatusEffectConfig |
|---------------|---|-------------------|
| `id` | → | `type` |
| `duration` (秒) | → | `duration` (毫秒) |
| `value` | → | `value` |
| `probability` | → | `chance` |
| `category` | → | `category` |

## 🔍 關鍵設計要點

### 1. ✅ 單一職責原則
- **WeaponBasic**: 負責從屬性生成狀態效果配置
- **CombatSystem**: 負責應用狀態效果到目標
- **ProjectileBasic**: 負責在命中時觸發狀態效果

### 2. ✅ 配置驅動
- 所有狀態效果定義來自 Google Sheets
- 武器通過 `effectProperties` 配置狀態效果列表
- 運行時從 `PropertyValue[]` 動態生成

### 3. ✅ 類型安全
```typescript
PropertyValue (屬性系統)
    ↓ generateStatusEffects()
StatusEffectConfig (戰鬥系統)
    ↓ CombatSystem
StatusEffect Schema (同步層)
```

### 4. ✅ 機率觸發
- 只包含 `probability > 0` 的效果
- CombatSystem 在應用時根據 `chance` 判斷是否觸發
- 支持多個狀態效果同時判定
