## 🎯 **重要設計決策記錄**

1. **屬性統一**: 天賦直接使用 WeaponProperties，避免重複定義
2. **配置驅動**: 所有天賦資料由 Google Sheets 管理，支援熱更新  
3. **需求鏈**: 使用 prerequisites 而非 tier 層級概念
4. **點數固定**: 每級1點，每個天賦消耗1點，簡化計算
5. **觸發靈活**: 支援被動、條件觸發等多種效果類型
