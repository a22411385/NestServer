## 📝 重要決策記錄

### 1. 為什麼移除隨機屬性?
- **舊系統**: 武器屬性完全隨機,難以平衡
- **新系統**: 固定屬性配方,玩家可預測武器效果
- **優勢**: 更好的遊戲體驗和平衡性

### 2. 為什麼使用 MapSchema<number>?
- **類型**: `MapSchema<number>` (key: MaterialType, value: quantity)
- **優勢**: Colyseus 原生支持,自動同步
- **迭代**: 使用 `Object.entries()` 轉換為陣列

### 3. 為什麼刪除 WeaponPropertyService?
- **原因**: 舊系統的隨機屬性生成邏輯已被新系統取代
- **影響**: 代碼量減少 414 行,提升可維護性
- **結果**: TypeScript 編譯 0 錯誤
