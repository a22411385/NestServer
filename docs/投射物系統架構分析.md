# 投射物系統架構分析：ProjectileBasic 與 ServerBullet 的關係

## 📊 架構總覽

```
┌─────────────────────────────────────────────────────────────┐
│                    投射物系統雙層架構                          │
└─────────────────────────────────────────────────────────────┘

┌──────────────────────┐         ┌──────────────────────┐
│   ServerBullet       │         │   ProjectileBasic    │
│   (物理載體)          │  關聯   │   (邏輯處理器)        │
│   Schema同步         │◄────────│   命中效果           │
└──────────────────────┘         └──────────────────────┘
         │                                  │
         │ 提供位置/速度                      │ 處理命中邏輯
         │                                  │
         ▼                                  ▼
    客戶端渲染                          AttackResult
  (BulletManager)                    (傷害/視覺效果)
```

---

## 🎯 職責分工

### **ServerBullet (物理載體層)**

**角色：** 網路同步的物理實體，負責子彈的移動和存在狀態

**職責：**
1. ✅ **位置同步** - 通過 Colyseus Schema 自動同步到客戶端
2. ✅ **物理移動** - 計算當前位置、飛行距離、速度
3. ✅ **生命週期** - 判斷何時應該被銷毀
4. ✅ **基礎屬性** - 儲存發射者、方向、起點、時間戳

**重要方法：**
```typescript
class ServerBullet extends Schema {
    // 📡 同步到客戶端的屬性
    @type("string") id: string;
    @type("string") ownerId: string;
    @type(Vector2) startPosition: Vector2;
    @type(Vector2) direction: Vector2;
    @type("number") speed: number;
    @type("number") startTime: number;
    @type("string") bulletType: string; // ← 連結到 ProjectileBasic
    
    // 🎯 非同步屬性（僅伺服器端使用）
    damage: number;
    pierceCount: number;
    maxDistance: number;
    
    // 📍 計算當前位置（用於碰撞檢測）
    getCurrentPosition(): Vector2 { ... }
    
    // 🏁 判斷是否應該銷毀
    shouldDestroy(): boolean {
        return this.pierceCount <= 0 || 
               this.getTraveledDistance() >= this.maxDistance;
    }
}
```

**不負責：**
- ❌ 命中邏輯處理
- ❌ 傷害計算
- ❌ 視覺效果生成
- ❌ AOE 範圍搜索

---

### **ProjectileBasic (邏輯處理層)**

**角色：** 策略模式的命中處理器，定義子彈命中時的行為

**職責：**
1. ✅ **命中邏輯** - 處理子彈擊中目標時的效果
2. ✅ **傷害計算** - 根據類型調整傷害值
3. ✅ **目標搜索** - AOE 範圍內尋找受影響的目標
4. ✅ **視覺效果** - 生成 VisualEffect 數據（爆炸、冰凍等）
5. ✅ **返回結果** - 構建標準的 AttackResult

**重要方法：**
```typescript
abstract class ProjectileBasic {
    // 🎯 投射物配置
    projectileType: string;
    weaponId: string;
    baseDamage: number;
    pierceCount: number;
    areaOfEffect: number;
    
    // 🎭 命中處理（模板方法模式）
    public onHit(
        bullet: ServerBullet,        // ← 接收物理載體
        hitTarget: ServerGameUnit,
        gameRoom: GameRoom
    ): AttackResult {
        // 1. 尋找受影響的目標（由子類實現）
        const targets = this.findAffectedTargets(bullet, hitTarget, gameRoom);
        
        // 2. 計算傷害（子類可覆寫）
        const damage = this.calculateDamage(bullet, hitTarget);
        
        // 3. 減少穿透次數
        this.pierceCount--;
        
        // 4. 構建攻擊結果
        return this.buildAttackResult(bullet, targets, damage);
    }
    
    // 🔍 尋找受影響的目標（子類必須實現）
    protected abstract findAffectedTargets(...): ServerGameUnit[];
    
    // 💥 創建視覺效果（子類必須實現）
    protected abstract createVisualEffects(...): VisualEffect[];
    
    // 🎨 應用投射物配置（子類必須實現）
    protected abstract applyProjectileConfig(): void;
}
```

**不負責：**
- ❌ 位置計算（由 ServerBullet 負責）
- ❌ 網路同步（由 ServerBullet 的 Schema 自動處理）
- ❌ 碰撞檢測（由 BulletSystem 負責）

## 🔗 兩者如何協作

### **1. 創建階段**

```typescript
// CombatSystem.ts
createProjectilesFromAttackResult(hero, attackResult) {
    const visualEffect = attackResult.visualEffects[0];
    
    // 🚀 步驟 1: 創建物理載體（ServerBullet）
    bulletSystem.spawnBullet({
        ownerId: hero.id,
        startPosition: visualEffect.position,
        direction: visualEffect.direction,
        damage: visualEffect.data.damage,
        speed: visualEffect.data.speed,
        bulletClass: 'ExplosiveProjectile',  // ← 指定邏輯處理器類型
        pierceCount: 1,
        maxDistance: 400
    });
}

// BulletFactory.ts
createBullet(config) {
    const bullet = new ServerBullet();
    
    bullet.initialize(
        bulletId,
        config.ownerId,
        config.startPosition,
        config.direction,
        config.damage,
        config.speed,
        config.bulletClass,  // ← 'ExplosiveProjectile'
        config.weaponId,
        config.maxDistance,
        config.pierceCount
    );
    
    return bullet; // ← 只返回物理載體，邏輯處理器稍後創建
}
```

**重點：**
- ServerBullet 儲存 `bulletType = 'ExplosiveProjectile'`
- 這個字串稍後用於創建對應的 ProjectileBasic 實例

### **2. 飛行階段**

```typescript
// BulletSystem.ts
updateBullets(deltaTime) {
    for (const [bulletId, bullet] of this.bullets) {
        // ✅ ServerBullet 自己判斷是否應該銷毀
        if (bullet.shouldDestroy()) {
            bulletsToRemove.push(bulletId);
            continue;
        }
        
        // ✅ ServerBullet 提供當前位置
        this.checkBulletCollisions(bullet);
    }
}

checkBulletCollisions(bullet: ServerBullet) {
    const currentPos = bullet.getCurrentPosition(); // ← ServerBullet 提供
    
    for (const enemy of enemies) {
        if (this.isBulletHitEnemy(bullet, enemy, currentPos)) {
            // 🎯 命中了！交給 ProjectileBasic 處理
            this.handleBulletHit(bullet, enemy);
        }
    }
}
```

**重點：**
- ServerBullet 提供位置計算和碰撞判定
- ProjectileBasic 尚未介入

### **3. 命中階段（核心協作）**

```typescript
// BulletSystem.ts
handleBulletHit(bullet: ServerBullet, enemy: ServerEnemy) {
    const owner = gameRoom.state.gameCore.allUnits.get(bullet.ownerId);
    
    // 🎭 步驟 1: 根據 bulletType 創建對應的邏輯處理器
    const projectile = ProjectileFactory.getProjectile(
        bullet.bulletType,    // ← 'ExplosiveProjectile'
        bullet.weaponId,
        bullet.damage
    );
    
    // 🎯 步驟 2: 邏輯處理器處理命中
    const attackResult = projectile.onHit(bullet, enemy, gameRoom);
    //                   ▲                  ▲
    //              邏輯處理器          物理載體
    
    // 📡 步驟 3: 廣播攻擊結果
    gameRoom.broadcast('projectile_attack', {
        projectileId: bullet.id,
        attackResult: attackResult,  // ← 包含視覺效果、受影響目標等
        timestamp: Date.now()
    });
    
    // 💥 步驟 4: 對所有受影響的目標造成傷害
    for (const targetId of attackResult.targetIds) {
        const target = gameRoom.state.gameCore.allUnits.get(targetId);
        damageSystem.dealDamageToTarget({
            attacker: owner,
            target: target,
            baseDamage: attackResult.baseDamage,
            damageType: 'physical',
            source: `projectile_${bullet.bulletType}`,
            position: bullet.getCurrentPosition()  // ← ServerBullet 提供位置
        });
    }
}
```

**協作流程：**
```
ServerBullet (物理)          ProjectileBasic (邏輯)
      │                              │
      │ bulletType: 'ExplosiveProjectile'
      │                              │
      ▼                              ▼
 getCurrentPosition()      ──►  onHit(bullet, enemy, gameRoom)
      │                              │
      │                              ├─► findAffectedTargets()
      │                              │   (範圍內搜索敵人)
      │                              │
      │                              ├─► calculateDamage()
      │                              │   (調整傷害值)
      │                              │
      │                              ├─► createVisualEffects()
      │                              │   (生成爆炸效果)
      │                              │
      │                              └─► buildAttackResult()
      │                                   (構建統一結果)
      │                              │
      ▼                              ▼
   pierceCount--              AttackResult {
 (減少穿透次數)                  targetIds: [...],
                                baseDamage: 40,
                                visualEffects: [
                                    { type: 'explosion', ... }
                                ]
                             }
```

## 🎨 具體範例：爆炸投射物

### **ServerBullet 的視角**

```typescript
// ServerBullet 實例
{
    id: "bullet_001",
    ownerId: "hero_123",
    startPosition: { x: 100, y: 200 },
    direction: { x: 1, y: 0 },
    speed: 300,
    startTime: 1697523456789,
    bulletType: "ExplosiveProjectile",  // ← 指向邏輯處理器
    
    // 非同步屬性
    damage: 50,
    pierceCount: 1,
    maxDistance: 400
}

// 我的職責：
getCurrentPosition() {
    const elapsed = (Date.now() - this.startTime) / 1000;
    const distance = this.speed * elapsed;
    return {
        x: this.startPosition.x + this.direction.x * distance,
        y: this.startPosition.y + this.direction.y * distance
    };
}

shouldDestroy() {
    return this.pierceCount <= 0 || 
           this.getTraveledDistance() >= this.maxDistance;
}
```

### **ExplosiveProjectile 的視角**

```typescript
// ExplosiveProjectile 實例
class ExplosiveProjectile extends ProjectileBasic {
    projectileType: "ExplosiveProjectile",
    weaponId: "weapon_bow",
    baseDamage: 50,
    pierceCount: 1,
    areaOfEffect: 80,  // ← 爆炸範圍
    
    // 我的職責：
    onHit(bullet: ServerBullet, enemy: ServerEnemy, gameRoom: GameRoom) {
        // 1️⃣ 獲取爆炸中心（從 bullet 讀取）
        const explosionCenter = bullet.getCurrentPosition();
        
        // 2️⃣ 搜索範圍內的所有敵人
        const targets = this.findTargetsInRadius(
            explosionCenter,
            this.areaOfEffect,  // 80 像素範圍
            gameRoom
        );
        // 結果：[enemy1, enemy2, enemy3]
        
        // 3️⃣ 計算傷害（爆炸傷害降低）
        const damage = Math.floor(this.baseDamage * 0.8); // 50 * 0.8 = 40
        
        // 4️⃣ 生成爆炸視覺效果
        const visualEffects = [{
            type: 'explosion',
            position: explosionCenter,
            data: {
                radius: 80,
                colors: [0xff4400, 0xffaa00],
                duration: 400,
                hasShockwave: true
            }
        }];
        
        // 5️⃣ 返回攻擊結果
        return {
            success: true,
            weaponId: this.weaponId,
            targetIds: ['enemy1', 'enemy2', 'enemy3'],
            baseDamage: 40,
            visualEffects: visualEffects
        };
    }
}
```

```
4️⃣ 命中階段
   BulletSystem.handleBulletHit()
   ├─► ProjectileFactory.getProjectile(bullet.bulletType)
```

## 🎯 設計模式

### **1. 策略模式 (Strategy Pattern)**

```typescript
// ServerBullet 是環境（Context）
class ServerBullet {
    bulletType: string; // ← 指向策略
}

// ProjectileBasic 是抽象策略
abstract class ProjectileBasic {
    abstract onHit(...): AttackResult;
}

// ExplosiveProjectile, PiercingProjectile 是具體策略
class ExplosiveProjectile extends ProjectileBasic { ... }
class PiercingProjectile extends ProjectileBasic { ... }
```

**優勢：**
- ✅ 同樣的 ServerBullet 可以有不同的命中行為
- ✅ 新增投射物類型不需要修改 ServerBullet
- ✅ 符合開閉原則（Open-Closed Principle）

---

### **2. 工廠模式 + 註冊表模式**

```typescript
// 註冊表模式
class ProjectileRegistry {
    private static registry: Map<string, Constructor> = new Map();
    
    static {
        this.register('ExplosiveProjectile', ExplosiveProjectile);
        this.register('PiercingProjectile', PiercingProjectile);
    }
    
    static create(className: string, ...args): ProjectileBasic {
        const Constructor = this.registry.get(className);
        return new Constructor(...args);
    }
}

// 工廠模式
class ProjectileFactory {
    static getProjectile(bulletType: string, ...args): ProjectileBasic {
        return ProjectileRegistry.create(bulletType, ...args);
    }
}
```

**優勢：**
- ✅ 支援類名反射（字串 → 實例）
- ✅ 易於擴充（只需註冊新類別）
- ✅ 集中管理所有投射物類型

---

### **3. 模板方法模式 (Template Method Pattern)**

```typescript
abstract class ProjectileBasic {
    // 模板方法 - 定義骨架
    public onHit(bullet, target, gameRoom): AttackResult {
        // 1. 檢查碰撞範圍（通用）
        if (!this.isWithinCollisionRange(bullet, target)) {
            return failResult;
        }
        
        // 2. 尋找目標（子類實現） ← Hook
        const targets = this.findAffectedTargets(bullet, target, gameRoom);
        
        // 3. 計算傷害（子類可覆寫） ← Hook
        const damage = this.calculateDamage(bullet, target);
        
        // 4. 構建結果（通用）
        return this.buildAttackResult(bullet, targets, damage);
    }
    
    // Hook 方法
    protected abstract findAffectedTargets(...): ServerGameUnit[];
    protected abstract createVisualEffects(...): VisualEffect[];
}
```

**優勢：**
- ✅ 定義統一的處理流程
- ✅ 子類只需實現差異部分
- ✅ 避免重複代碼

## ✅ 優勢總結

### **1. 職責分離**
- ServerBullet 專注於**物理移動和同步**
- ProjectileBasic 專注於**邏輯處理和效果**

### **2. 易於擴充**
```typescript
// 新增冰凍投射物只需 3 步：

// 1️⃣ 創建新類別
class FreezeProjectile extends ProjectileBasic {
    applyProjectileConfig() {
        this.areaOfEffect = 60;
        this.pierceCount = 1;
    }
    
    findAffectedTargets(...) {
        // 範圍內的敵人
    }
    
    createVisualEffects(...) {
        return [{ type: 'freeze', ... }];
    }
}

// 2️⃣ 註冊類別
ProjectileRegistry.register('FreezeProjectile', FreezeProjectile);

// 3️⃣ 使用
bulletSystem.spawnBullet({
    bulletClass: 'FreezeProjectile',
    ...
});
```

### **3. 複用性高**
- ServerBullet 可以被任何投射物類型使用
- ProjectileBasic 的輔助方法可以被所有子類共享

### **4. 類型安全**
- TypeScript 編譯期檢查
- 註冊表模式確保類名正確

### **5. 易於測試**
```typescript

const bullet = new ServerBullet();

// 測試邏輯處理
```

## 🚨 注意事項

### **1. ServerBullet 的 pierceCount 同步問題**

```typescript
// ❌ 問題：pierceCount 不在 Schema 中
class ServerBullet extends Schema {
    // @type("number") pierceCount: number = 1; ← 未同步
    pierceCount: number = 1; // ← 僅伺服器端屬性
}

// ✅ 影響：
// - 客戶端無法知道子彈還能穿透幾次
// - 客戶端渲染依賴 onRemove 事件觸發銷毀
// - 伺服器端負責所有邏輯判斷
```

**決策：** 目前設計是正確的，因為客戶端不需要知道 pierceCount，只需要渲染飛行中的子彈。

### **2. ProjectileFactory 的快取機制**

```typescript
// ⚠️ 注意：ProjectileFactory 使用單例快取
const cacheKey = `${projectileClassName}_${weaponId}_${baseDamage}`;

// 影響：
// - 相同參數會返回同一個實例
// - pierceCount 會被修改（bullet.pierceCount--）
// - 必須確保每次命中後正確重置或創建新實例
```

**建議：** 考慮每次命中時創建新的 ProjectileBasic 實例，而不是使用快取。

### **3. bulletType vs projectileType**

```typescript
ServerBullet.bulletType     = "ExplosiveProjectile"  // ← 字串，用於創建邏輯處理器
ProjectileBasic.projectileType = "ExplosiveProjectile"  // ← 字串，儲存類型名稱

// 兩者應該一致！
```

## 🎯 總結

| 特性 | ServerBullet | ProjectileBasic |
|------|--------------|-----------------|
| **角色** | 物理載體 | 邏輯處理器 |
| **職責** | 位置、速度、生命週期 | 命中效果、傷害、視覺 |
| **同步** | ✅ Schema 自動同步 | ❌ 僅伺服器端 |
| **創建時機** | 武器發射時 | 子彈命中時 |
| **生命週期** | 與飛行過程同步 | 僅在命中瞬間 |
| **擴充性** | 固定 Schema | 無限擴充子類 |
| **依賴關係** | 獨立 | 依賴 ServerBullet 提供位置 |

**核心關係：**
```typescript
ServerBullet.bulletType === ProjectileBasic.constructor.name
//  ▲                               ▲
//  │                               │
//  └─────────── 字串連結 ────────────┘
```

**最佳實踐：**
1. ServerBullet 只負責「飛」
2. ProjectileBasic 只負責「打」
3. BulletSystem 負責「檢測碰撞」
4. DamageSystem 負責「實際扣血」

這種分層架構確保了**高內聚、低耦合**的設計原則！ 🚀
