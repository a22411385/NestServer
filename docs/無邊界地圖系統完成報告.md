# 無邊界地圖系統完成報告

## 📋 需求概述

將遊戲地圖從固定邊界改為無邊界模式：
- 敵人生成點從地圖邊緣改為玩家周圍半徑 2000 距離的圓周
- 客戶端背景改為無限平鋪跟隨
- 移除所有地圖邊界限制

## ✅ 完成項目

### 1. 伺服器端 - 敵人生成系統

**檔案**: `NestServer/src/Game/Managers/SpawnManager/SpawnManager.ts`

#### 新增功能
- **`getCircleAroundPlayersPositions()`** 方法
  - 在所有玩家的中心點周圍生成敵人
  - 固定半徑：2000 像素
  - 半徑隨機變化：±100 像素（1900-2100）
  - 如果沒有玩家，在原點(0,0)周圍生成

- **`isValidSpawnPositionNoBounds()`** 方法
  - 不檢查地圖邊界
  - 確保敵人至少距離玩家 1800 像素
  - 仍然檢查敵人之間的最小距離

#### 修改邏輯
```typescript
// 將 RANDOM_EDGE 和 default 改為使用新的圓周生成
case SpawnType.RANDOM_EDGE:
    return this.getCircleAroundPlayersPositions(config, existingUnits);
```

#### 生成算法
1. 計算所有玩家的中心點：
   ```typescript
   centerX = sum(player.x) / playerCount
   centerY = sum(player.y) / playerCount
   ```

2. 在中心點周圍的圓周上生成：
   ```typescript
   angle = random(0, 2π)
   radius = 2000 + random(-100, 100)
   x = centerX + cos(angle) * radius
   y = centerY + sin(angle) * radius
   ```

3. 驗證位置：
   - 與玩家距離 ≥ 1800
   - 與其他敵人距離 ≥ minDistanceBetweenEnemies

### 3. 客戶端 - 無限平鋪背景

**檔案**: `ViteRPG/src/Game/GameScene.ts`

#### 新增屬性
```typescript
private backgroundTileSprite?: Phaser.GameObjects.TileSprite;
```

#### 重寫 `createBackgroundGrid()` 方法

**舊版本**（固定大小網格）：
```typescript
// 在固定範圍內繪製網格線
for (let x = -halfWorldW; x <= halfWorldW; x += gridSize) {
    graphics.moveTo(x, -halfWorldH);
    graphics.lineTo(x, halfWorldH);
}
```

**新版本**（無限平鋪）：
```typescript
// 1. 創建 1000x1000 的網格紋理
const graphics = this.add.graphics();
graphics.lineStyle(1, 0x333333, 0.3);
for (let x = 0; x <= tileSize; x += gridSize) {
    graphics.moveTo(x, 0);
    graphics.lineTo(x, tileSize);
}
graphics.generateTexture('bgGrid', tileSize, tileSize);

// 2. 使用 TileSprite 創建可平鋪的背景
this.backgroundTileSprite = this.add.tileSprite(
    0, 0,
    screenWidth * 4,
    screenHeight * 4,
    'bgGrid'
);
this.backgroundTileSprite.setDepth(-100000);
```

#### 更新 `update()` 方法
```typescript
// 每幀更新背景位置，跟隨玩家
if (this.backgroundTileSprite && viewTarget) {
    this.backgroundTileSprite.setPosition(viewTarget.x, viewTarget.y);
    this.backgroundTileSprite.setTilePosition(viewTarget.x, viewTarget.y);
}
```

**原理**：
- `setPosition()`: 讓背景物件跟隨玩家
- `setTilePosition()`: 平移紋理偏移，創造無限滾動錯覺

## 🎮 遊戲體驗變化

### 之前（有邊界）
- 敵人固定在地圖四個邊緣生成
- 玩家被限制在固定區域（2000x2000）
- 擊退效果會被邊界阻擋
- 背景是固定大小的網格

### 之後（無邊界）
- ✅ 敵人始終在玩家周圍 2000 像素的圓周生成
- ✅ 玩家可以無限移動，沒有邊界
- ✅ 擊退效果不受限制
- ✅ 背景無限平鋪跟隨，視覺上永遠有網格

## 📊 技術細節

### 生成位置計算

**多玩家場景**：
```
玩家A: (100, 200)
玩家B: (300, 400)
中心點: ((100+300)/2, (200+400)/2) = (200, 300)

敵人生成範圍：以(200, 300)為圓心，半徑2000的圓周
```

**單玩家場景**：
```
玩家: (500, 600)
中心點: (500, 600)

敵人生成範圍：以(500, 600)為圓心，半徑2000的圓周
```

### 無限背景原理

**TileSprite 平鋪機制**：
1. 創建可重複的紋理單元（1000x1000）
2. 使用 `tilePosition` 控制紋理偏移
3. 當偏移超過紋理大小時，自動循環重複

**範例**：
```
玩家移動到 (3500, 4200)
→ setPosition(3500, 4200)      // 背景物件跟隨
→ setTilePosition(3500, 4200)  // 紋理偏移 3500%1000=500, 4200%1000=200
→ 視覺上看起來像無限延伸的網格
```

## 🐛 潛在問題

### 1. 數值溢出風險
**問題**：如果玩家移動到極遠位置（如 x > 1,000,000），可能導致：
- 浮點數精度損失
- 物理計算異常

**建議**：考慮添加軟性限制（如 -100000 到 100000）

### 2. 敵人永遠跟隨
**問題**：敵人始終在玩家周圍生成，玩家無法"甩掉"敵人

**建議**：如果需要安全區，可以添加條件判斷暫停生成

### 3. 視野範圍外的敵人
**問題**：敵人在 2000 距離生成，可能超出玩家視野範圍

**建議**：確保玩家視野範圍 ≥ 2000，或添加小地圖指示
