# 投射物系統重構完成報告

## 🎯 **重構目標達成**

### ✅ **問題解決**

2. **統一AttackResult** - 投射物系統現在返回標準的 AttackResult，與武器系統保持一致

## 🔧 **系統架構**

### **投射物基礎類 (ProjectileBasic)**
```typescript
abstract class ProjectileBasic {
    // 類似武器系統的架構
    abstract onHit(bullet, hitTarget, gameRoom): AttackResult;
    abstract findAffectedTargets(...): ServerGameUnit[];
    abstract shouldContinueAfterHit(bullet): boolean;
}
```

### **工廠模式 (ProjectileFactory)**
```typescript
ProjectileFactory.getProjectile(projectileType, weaponId, baseDamage)
// 支援類型: "basic", "explosive", "piercing", "freeze"
```

### **統一的攻擊結果**
```typescript
// 投射物返回標準 AttackResult
{
    success: boolean,
    weaponId: string,
    targetIds: string[],
    baseDamage: number,
    attackData: {...},
    visualEffects: [...]
}
```

## 💡 **設計優勢**

### 1. **職責分離**
- `ServerBullet`: 只負責移動、碰撞檢測、基本狀態
- `ProjectileBasic`: 負責命中邏輯、目標選擇、效果處理
- `BulletSystem`: 統一管理所有投射物的生命周期

### 2. **擴展性強**
- 新增投射物類型只需繼承 `ProjectileBasic`
- 無需修改現有的 `BulletSystem` 或 `ServerBullet`
- 工廠模式支援緩存和性能優化

### 3. **統一接口**
- 與武器系統使用相同的 `AttackResult` 結構
- 可以重用 `DamageSystem` 和 `CombatSystem` 的邏輯
- 視覺效果系統統一

### 4. **類型安全**
- TypeScript 支援完整
- 編譯時錯誤檢查
- IDE 智能提示

## 🚀 **目前支援的投射物類型**

### **基礎投射物 (BasicProjectile)**
- 單體攻擊
- 命中後消失
- 無特殊效果

### **爆炸投射物 (ExplosiveProjectile)**
- 命中後產生範圍爆炸
- 影響爆炸半徑內所有敵人
- 傷害稍微降低（80%）

### **穿透投射物 (PiercingProjectile)**
- 可以穿透多個敵人（預設3個）
- 每次命中減少穿透次數
- 穿透次數用完後消失

### **冰凍投射物 (FreezeProjectile)**
- 命中後造成冰凍效果
- 降低敵人移動速度
- 效果持續2秒

## 🎮 **使用示例**

### **在武器中創建投射物**
```typescript
// ProjectileWeapon.createProjectileVisualEffects()
return [{
    type: 'projectile',
    data: {
        bulletType: 'explosive', // 指定投射物類型
        weaponId: this.weaponId
    }
}];
```

### **BulletSystem 自動處理**
```typescript
// 系統自動根據 bulletType 選擇對應的投射物類型
const projectile = ProjectileFactory.getProjectile(
    bullet.bulletType,
    bullet.weaponId, 
    bullet.damage
);

const attackResult = projectile.onHit(bullet, enemy, gameRoom);
```
