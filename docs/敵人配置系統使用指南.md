# 敵人配置系統使用指南

## 📋 概述

敵人配置系統允許通過 Google Sheets 動態擴充敵人種類，無需修改代碼即可添加新的敵人類型。

## 🗂️ 系統架構

```
Google Sheets (EnemyConfigs) 
    ↓
GoogleSheetCache.ts (載入數據)
    ↓
google-sheets-cache.json
    ↓
ConfigManager.ts (提供API)
    ↓
EnemyFactory.ts (創建敵人實例)
    ↓
WaveManager.ts (波次管理)
```

## 📊 EnemyConfigs.csv 結構

### 必填欄位

| 欄位 | 類型 | 說明 | 範例 |
|------|------|------|------|
| `id` | string | 唯一識別碼 | `zombie_normal` |
| `name` | string | 內部名稱 | `Zombie` |
| `displayName` | string | 顯示名稱（支持 `{wave}` 模板） | `殭屍 Lv.{wave}` |
| `description` | string | 敵人描述 | `基礎的不死族敵人` |
| `category` | string | 類別 | `undead` / `beast` / `demon` |
| `baseHp` | number | 基礎血量 | `100` |
| `baseAttackDamage` | number | 基礎攻擊力 | `15` |
| `baseMoveSpeed` | number | 基礎移動速度 | `60` |
| `baseExpReward` | number | 基礎經驗獎勵 | `10` |
| `baseGoldReward` | number | 基礎金幣獎勵 | `5` |
| `scale` | number | 模型縮放 | `1.0` |
| `collisionWidth` | number | 碰撞寬度 | `32` |
| `collisionHeight` | number | 碰撞高度 | `64` |
| `aiType` | string | AI類型 | `aggressive` |
| `spawnWeight` | number | 生成權重 | `100` |
| `minWave` | number | 最小波次 | `1` |
| `maxWave` | number | 最大波次（0=無限制） | `0` |
| `enabled` | boolean | 是否啟用 | `TRUE` |

### 可選欄位

| 欄位 | 類型 | 說明 | 範例 |
|------|------|------|------|
| `specialAbilities` | string | 特殊能力（逗號分隔） | `regeneration,stun_attack` |
| `iconPath` | string | 圖標路徑 | `/assets/icons/zombie.png` |
| `modelPath` | string | 模型路徑 | `/assets/models/zombie.glb` |

## 🎮 AI類型說明

| AI類型 | 行為描述 | 適用場景 |
|--------|----------|----------|
| `aggressive` | 快速接近並攻擊 | 近戰敵人 |
| `chase` | 追逐玩家 | 標準敵人 |
| `tank` | 緩慢移動，高血量 | 肉盾型 |
| `boss` | Boss特殊行為 | Boss戰 |
| `ranged` | 遠程攻擊 | 弓箭手/法師 |
| `summoner` | 召喚其他敵人 | 召喚者 |
| `stealth` | 隱身接近 | 刺客型 |
| `phantom` | 穿牆/傳送 | 幽靈型 |
| `ambush` | 伏擊行為 | 埋伏型 |
| `elite` | 精英強化版 | 精英怪 |

## ⚙️ 波次權重系統

### 權重計算邏輯

系統根據 `spawnWeight` 進行加權隨機選擇：

```typescript
// 第6波可生成的敵人
zombie_normal: weight 100 (67%)
werewolf_hunter: weight 50 (33%)
總權重 = 150

// 隨機數 0-150
0-100 → zombie_normal
100-150 → werewolf_hunter
```

### 推薦權重配置

| 權重範圍 | 稀有度 | 生成頻率 | 適用敵人 |
|----------|--------|----------|----------|
| 100-150 | Common | 極高 | 基礎敵人 |
| 50-90 | Uncommon | 高 | 標準變種 |
| 20-40 | Rare | 中等 | 精英敵人 |
| 10-15 | Epic | 低 | 小Boss |
| 1-5 | Legendary | 極低 | 超級Boss |

## 🔧 ConfigManager API

### 獲取敵人配置

```typescript
import { ConfigManager } from '@/Game/Managers/ConfigManager';

// 獲取所有敵人配置
const allEnemies = ConfigManager.getEnemyConfigs();

// 根據ID獲取單個配置
const zombie = ConfigManager.getEnemyConfigById('zombie_normal');

// 根據波次獲取可生成的敵人
const wave6Enemies = ConfigManager.getEnemiesByWave(6);

// 根據分類篩選
const undeadEnemies = ConfigManager.getEnemiesByCategory('undead');

// 隨機選擇敵人ID（加權）
const randomEnemyId = ConfigManager.getRandomEnemyIdByWave(10);

// 獲取啟用的敵人
const enabled = ConfigManager.getEnabledEnemies();
```

## 🏭 EnemyFactory API

### 創建敵人實例

```typescript
import { EnemyFactory } from '@/Game/Factories/EnemyFactory';
import { Vector2 } from '@/Colyseus/Schema/Unit/GameUnit';

// 1️⃣ 指定ID創建敵人
const zombie = EnemyFactory.createEnemy(
    'zombie_normal',
    new Vector2(100, 100),
    5 // Wave 5
);

// 2️⃣ 根據波次隨機生成（推薦）
const randomEnemy = EnemyFactory.createRandomEnemyByWave(
    new Vector2(200, 200),
    10 // Wave 10
);

// 3️⃣ 獲取金幣獎勵
const goldReward = EnemyFactory.getGoldReward('zombie_normal', 5);

// 4️⃣ 獲取波次可用敵人ID列表
const availableIds = EnemyFactory.getAvailableEnemyIds(6);
// ['zombie_normal', 'zombie_fast', 'werewolf_hunter']

// 5️⃣ 根據AI類型篩選
const bossIds = EnemyFactory.getEnemiesByAIType(10, 'boss');
// ['werewolf_alpha']

// 6️⃣ 計算波次敵人數量
const count = EnemyFactory.calculateEnemyCount(8);
// 50 = 10 + (8 * 5)
```

## 📝 添加新敵人的步驟

### 1. 在 Google Sheets 添加新行

```csv
id,name,displayName,description,category,baseHp,...
vampire_noble,Vampire Noble,吸血鬼貴族 Lv.{wave},高貴的吸血鬼,undead,300,30,80,40,20,1.2,36,68,elite,25,12,0,life_drain|teleport,/assets/icons/vampire.png,/assets/models/vampire.glb,TRUE
```

### 2. 更新快取數據

```bash
npm run cache:update
```

### 3. 重啟服務器

```bash
npm run start:dev
```

### 4. 驗證

```typescript
// 檢查是否載入成功
const vampire = ConfigManager.getEnemyConfigById('vampire_noble');
console.log(vampire); // 應該顯示配置數據

// 測試生成
const enemy = EnemyFactory.createEnemy(
    'vampire_noble',
    new Vector2(0, 0),
    12
);
console.log(enemy.name); // "吸血鬼貴族 Lv.12"
console.log(enemy.hp); // 基於 baseHp 和波次加成計算
```

## 🎯 屬性縮放公式

### 波次加成計算

```typescript
// HP 縮放：每波 +15%
hpMultiplier = 1 + (waveNumber - 1) * 0.15
enemy.hp = baseHp * hpMultiplier

// 攻擊力縮放：每波 +10%
damageMultiplier = 1 + (waveNumber - 1) * 0.10
enemy.attackDamage = baseAttackDamage * damageMultiplier

// 大小縮放：每波 +5%，最大 1.5x
scaleMultiplier = min(1 + (waveNumber - 1) * 0.05, 1.5)
enemy.scale = baseScale * scaleMultiplier

// 經驗/金幣縮放：與HP相同
expMultiplier = hpMultiplier
enemy.expReward = baseExpReward * expMultiplier
```

### 範例計算

**Wave 1（zombie_normal）：**
- HP: 100 * 1.0 = **100**
- Damage: 15 * 1.0 = **15**
- Exp: 10 * 1.0 = **10**

**Wave 10（zombie_normal）：**
- HP: 100 * (1 + 9 * 0.15) = 100 * 2.35 = **235**
- Damage: 15 * (1 + 9 * 0.10) = 15 * 1.9 = **28**
- Exp: 10 * 2.35 = **23**

## 🐛 常見問題

### Q: 為什麼新敵人不生成？

**A: 檢查以下項目：**
1. `enabled` 是否為 `TRUE`
2. `minWave` 是否 ≤ 當前波次
3. `maxWave` 是否 0 或 ≥ 當前波次
4. `spawnWeight` 是否 > 0
5. 是否執行過 `npm run cache:update`

### Q: Boss不在Boss波次生成？

**A: 確認：**
1. `aiType` 設置為 `boss`
2. `minWave` 是5的倍數
3. 使用 `WaveManager` 的 Boss 生成邏輯

### Q: 屬性縮放不正確？

**A: 檢查：**
1. `enemy.lv` 是否正確設置為 `waveNumber`
2. `getWaveMultiplier()` 計算邏輯
3. `baseHp/baseAttackDamage` 是否設置正確

### Q: 金幣獎勵未生效？

**A: 確保：**
1. `baseGoldReward` 欄位已設置
2. DropSystem 調用 `EnemyFactory.getGoldReward()`
3. 波次加成應用正確
