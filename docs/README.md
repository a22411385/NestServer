## 📝 文檔維護

### 文檔更新原則
- **主要文檔**: 保持最新，反映當前系統狀態
- **參考文檔**: 提供深入的技術細節
- **歷史文檔**: 歸檔至 `archive/` 保留記錄

### 版本管理
- 每次重大更新後更新文檔版本號
- 在文檔底部標註最後更新時間
- 重要變更記錄在各文檔的變更日誌中
