**MaterialDropSystem** (材料掉落):
```typescript
class MaterialDropSystem {
  static rollMaterialDrops(enemy: ServerEnemy): MaterialDrop[] {
    const drops: MaterialDrop[] = [];
    
    // 根據敵人類型決定掉落
    const dropTable = MATERIAL_DROP_TABLES[enemy.type];
    
    dropTable.forEach(entry => {
      if (Math.random() < entry.chance) {
        // 加權隨機選擇稀有度
        const rarity = this.rollRarity();
        drops.push({
          materialType: entry.materialType,
          quantity: entry.quantity,
          rarity: rarity,
        });
      }
    });
    
    return drops;
  }
  
  private static rollRarity(): MaterialRarity {
    const rand = Math.random();
    if (rand < 0.05) return 'epic';    // 5%
    if (rand < 0.20) return 'rare';    // 15%
    return 'common';                    // 80%
  }
}
```

### 3. 戰鬥系統

#### 3.1 傷害計算

```typescript
class PropertyCalculationService {
  calculateDamage(attacker: ServerGameUnit, target: ServerGameUnit): number {
    // 1. 基礎傷害 (來自武器)
    let damage = attacker.attackDamage;
    
    // 2. 屬性加成
    if (attacker instanceof ServerHero) {
      // 力量加成: +1 ATK per 1 STR
      damage += attacker.str;
      // 武器力量加成
      damage += attacker.weaponStr;
    }
    
    // 3. 暴擊判定
    const isCrit = Math.random() < attacker.critRate;
    if (isCrit) {
      damage *= (1 + attacker.critDamage);
    }
    
    // 4. 防禦減免
    const defense = target.physicalDefense;
    damage = damage * (100 / (100 + defense));
    
    return Math.max(1, Math.floor(damage));
  }
}
```

#### 3.2 武器攻擊

**近戰武器** (Melee):
```typescript
class MeleeWeaponHandler {
  attack(hero: ServerHero, weapon: WeaponSchema) {
    // 1. 扇形範圍檢測
    const targets = this.findTargetsInRange(
      hero.position,
      hero.facingDirection,
      weapon.attackRange,
      weapon.sweepAngle // 60度
    );
    
    // 2. 對每個目標造成傷害
    targets.forEach(target => {
      const damage = this.calculateDamage(hero, target, weapon);
      target.hp -= damage;
      
      // 3. 觸發分支效果
      this.applyBranchEffect(target, weapon.craftingBranch);
    });
    
    // 4. 發送視覺效果
    this.room.broadcast('melee_swing', {
      heroId: hero.id,
      position: hero.position,
      direction: hero.facingDirection,
      weaponData: weapon,
    });
  }
}
```

## 🔄 數據流程

### 1. 材料掉落流程

```
1. 敵人死亡 (Server)
   ↓
2. MaterialDropSystem.rollMaterialDrops()
   ↓
3. DropSystem.spawnMaterial()
   ↓
4. 創建 ServerItem (MATERIAL 類型)
   ↓
5. 加入 gameCore.items (Colyseus State)
   ↓
6. 自動同步到 Client
   ↓
7. ItemManager.createItemVisual() (Client)
   ↓
8. 顯示材料圖示
```

### 2. 材料撿取流程

```
1. ItemPickupSystem.update() (Client)
   ↓
2. 檢測撿取範圍
   ↓
3. 發送 pickupItem 消息到 Server
   ↓
4. Server 驗證並處理
   ↓
5. hero.materials.set(type, quantity + 1)
   ↓
6. 自動同步到 Client
   ↓
7. MaterialInventory 自動更新顯示
```

### 3. 武器製作流程

```
1. 玩家點擊製作按鈕 (Client)
   ↓
2. GameServiceManager.craftWeapon(recipeId)
   ↓
3. 發送 craftWeapon 消息到 Server
   ↓
4. HeroWeaponManager.craftWeapon()
   ↓
5. WeaponCraftingSystem.craftWeapon()
   - 驗證材料、金幣、等級
   - 消耗資源
   - 成功率判定
   - 創建武器
   ↓
6. 返回 CraftingResult
   ↓
7. 發送 craftWeaponResult 到 Client
   ↓
8. 顯示製作結果訊息
   ↓
9. 武器自動加入背包 (Colyseus 同步)
```

function getMaterialConfig(type: MaterialType) {

## 🔐 安全性考量

### 1. 服務器驗證

所有遊戲邏輯在服務器執行,客戶端僅負責:
- 視覺呈現
- 輸入處理
- UI 互動

```typescript
// ✅ 正確: 服務器驗證
class HeroWeaponManager {
  craftWeapon(recipeId: string) {
    // 1. 驗證配方存在
    const recipe = getCraftingRecipe(recipeId);
    if (!recipe) return { success: false, message: '配方不存在' };
    
    // 2. 驗證等級
    if (this.hero.level < recipe.levelRequirement) {
      return { success: false, message: '等級不足' };
    }
    
    // 3. 驗證材料
    for (const mat of recipe.materials) {
      const owned = this.hero.materials.get(mat.materialType) || 0;
      if (owned < mat.quantity) {
        return { success: false, message: '材料不足' };
      }
    }
    
    // 4. 驗證金幣
    if (this.hero.gold < recipe.goldCost) {
      return { success: false, message: '金幣不足' };
    }
    
    // 5. 執行製作
    return this.craftingSystem.craftWeapon(recipe, this.hero);
  }
}
```
