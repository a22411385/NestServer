## 🎮 攻擊參數設計指南

### 1. 攻擊冷卻 (attackCooldown)

**定義**：兩次攻擊之間的最小間隔時間

```typescript
// 計算公式
攻擊頻率(次/秒) = 1000 / attackCooldown

// 範例
attackCooldown = 1000ms → 1 次/秒
attackCooldown = 800ms  → 1.25 次/秒
attackCooldown = 1500ms → 0.67 次/秒
```

**建議配置**：
- **普通敵人**: 1000-1200ms (標準速度)
- **快速敵人**: 700-900ms (高頻攻擊)
- **坦克敵人**: 1500-2000ms (緩慢但強力)
- **Boss**: 2000-3000ms (技能型攻擊)

### 2. 攻擊前搖 (attackWindupTime)

**定義**：攻擊動作開始到實際造成傷害的延遲時間

```typescript
// 玩家反應時間計算
可躲避距離 = 玩家移動速度 * (attackWindupTime / 1000)

// 範例：玩家速度 100 像素/秒
attackWindupTime = 300ms → 可移動 30 像素
attackWindupTime = 500ms → 可移動 50 像素
```

**建議配置**：
- **快速敵人**: 150-250ms (難躲避)
- **普通敵人**: 250-350ms (標準反應時間)
- **強力敵人**: 350-500ms (高傷害但易躲避)
- **Boss**: 500-1000ms (大招級攻擊)

### 3. 攻擊範圍 (attackRange)

**定義**：敵人能夠發動攻擊的最大距離

**建議配置**：
- **近戰敵人**: 50-70 像素
- **中距離敵人**: 70-100 像素
- **遠程敵人**: 100-200 像素
- **Boss**: 80-120 像素（視類型）

### 4. 平衡設計原則

#### 三角平衡

```
高攻速 ↔ 低傷害 ↔ 短前搖
  ↕         ↕         ↕
低攻速 ↔ 高傷害 ↔ 長前搖
```

#### 類型範例

**類型1：刺客型（高風險高回報）**
```typescript
{
    attackCooldown: 700,      // 快速攻擊
    attackWindupTime: 150,    // 短前搖（難躲避）
    attackRange: 50,          // 短距離
    baseDamage: 15            // 中等傷害
}
```

**類型2：坦克型（慢速重擊）**
```typescript
{
    attackCooldown: 1800,     // 緩慢攻擊
    attackWindupTime: 450,    // 長前搖（易躲避）
    attackRange: 70,          // 中等距離
    baseDamage: 30            // 高傷害
}
```

**類型3：平衡型（標準配置）**
```typescript
{
    attackCooldown: 1000,     // 標準攻擊速度
    attackWindupTime: 300,    // 標準前搖
    attackRange: 60,          // 標準距離
    baseDamage: 20            // 標準傷害
}
```

在 Google Sheets 中配置新敵人時，確保填寫：

- [ ] `id` - 唯一標識符

- [ ] `displayName` - 顯示名稱（支持 `{wave}` 模板）
- [ ] `baseHp` - 基礎生命值
- [ ] `baseAttackDamage` - 基礎攻擊力
- [ ] `baseMoveSpeed` - 移動速度
- [ ] `baseExpReward` - 經驗獎勵
- [ ] **`attackRange`** - 🆕 攻擊範圍
- [ ] **`attackCooldown`** - 🆕 攻擊冷卻
- [ ] **`attackWindupTime`** - 🆕 攻擊前搖
- [ ] `aiType` - AI 類型
- [ ] `spawnWeight` - 生成權重
- [ ] `minWave` / `maxWave` - 出現波次範圍

## 🐛 故障排除

### 問題1：敵人使用默認值而非配置值

**可能原因**：
- Google Sheets 欄位名稱拼寫錯誤
- 配置未正確載入
- 使用了舊的 `initializeByType()` 方法

**解決方案**：
```typescript
// 檢查配置是否載入
const config = ConfigManager.getById('EnemyConfigs', 'zombie_normal');
console.log(config);

// 應該看到 attackRange, attackCooldown, attackWindupTime
```

### 問題2：敵人攻擊沒有前搖

**檢查**：
```typescript
// 確認 windupDuration 是否設置
console.log(enemy.getWindupDuration()); // 應該顯示 300 等

// 檢查是否進入 windup 狀態
// 查看日誌是否有 "starts windup" 訊息
```

### 問題3：前搖時間過長或過短

**調整建議**：
1. 在 Google Sheets 中調整 `attackWindupTime`
2. 重啟伺服器
3. 重新測試
