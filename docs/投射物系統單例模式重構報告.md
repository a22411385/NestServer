# 投射物系統單例模式重構報告

## 📊 重構目的

### **問題分析**

```typescript
// ❌ 重構前：每次命中都創建新實例
第1次命中: new ExplosiveProjectile() → initialize() → onHit() → 丟棄
第2次命中: new ExplosiveProjectile() → initialize() → onHit() → 丟棄  // 浪費！
第3次命中: new ExplosiveProjectile() → initialize() → onHit() → 丟棄  // 浪費！

// ✅ 重構後：使用單例
第1次命中: ExplosiveProjectile.getInstance() → onHit()  // 創建唯一實例
第2次命中: ExplosiveProjectile.getInstance() → onHit()  // 返回同一實例
第3次命中: ExplosiveProjectile.getInstance() → onHit()  // 返回同一實例
```

### **核心洞察**

**ProjectileBasic 只儲存配置（不變的規則），不儲存狀態（會變的數據）**

```typescript
class ProjectileBasic {
    // ✅ 配置（固定不變）
    protected readonly initialPierceCount: number = 1;
    protected readonly areaOfEffect: number = 80;
    
    // ✅ 純函數方法（無副作用）
    onHit(bullet, enemy, gameRoom): AttackResult {
        bullet.pierceCount--;  // ← 修改的是 bullet，不是 this
        // ... 其他純邏輯
    }
}

class ServerBullet {
    // ✅ 狀態（會變化）
    pierceCount: number = 3;  // ← 這個會隨命中減少
    damage: number = 50;
    weaponId: string = "bow";
}
```

**結論：** 既然 ProjectileBasic 只有配置，沒有狀態，就不需要每次創建新實例！

## 🔧 重構內容

### **1. ProjectileBasic 改為單例基類**

**Before:**
```typescript
export abstract class ProjectileBasic {
  public projectileType: string = '';
  public weaponId: string = '';
  public baseDamage: number = 0;
  public pierceCount: number = 1;  // ← 狀態！（錯誤）
  
  constructor() {
    // 公開構造函數
  }
  
  public initialize(projectileType, weaponId, baseDamage): void {
    this.projectileType = projectileType;
    this.weaponId = weaponId;
    this.baseDamage = baseDamage;
    this.applyProjectileConfig();
  }
  
  onHit(bullet, enemy, gameRoom) {
    this.pierceCount--;  // ← 修改實例狀態（錯誤）
  }
}
```

**After:**
```typescript
export abstract class ProjectileBasic {
  // ✅ 只儲存配置（固定不變）
  protected readonly initialPierceCount: number = 1;
  protected readonly areaOfEffect: number = 0;
  protected readonly bounceCount: number = 0;
  protected readonly collisionRadius: number = 5;

  /**
   * 受保護的構造函數 - 強制使用單例模式
   */
  protected constructor() {
    this.applyProjectileConfig();
  }

  /**
   * ✅ 純函數方法（無副作用）
   * 所有狀態從參數獲取，不修改實例屬性
   */
  public onHit(
    bullet: ServerBullet,  // ← 狀態來自 bullet
    hitTarget: ServerGameUnit,
    gameRoom: GameRoom,
  ): AttackResult {
    // 所有數據從 bullet 獲取
    const damage = bullet.damage;
    const weaponId = bullet.weaponId;
    
    // 修改 bullet 的狀態，不修改 this
    bullet.pierceCount = Math.max(0, bullet.pierceCount - 1);
    
    // 使用配置
    const targets = this.findTargetsInRadius(
      bullet.getCurrentPosition(),
      this.areaOfEffect,  // ← 從配置獲取
      gameRoom
    );
    
    return {
      success: true,
      weaponId: weaponId,  // ← 從 bullet 獲取
      targetIds: targets.map(t => t.id),
      baseDamage: damage,  // ← 從 bullet 獲取
      // ...
    };
  }
}
```

**關鍵變更：**
1. ✅ 移除實例屬性：`projectileType`, `weaponId`, `baseDamage`, `pierceCount`
2. ✅ 保留配置屬性：`initialPierceCount`, `areaOfEffect` (設為 readonly)
3. ✅ 構造函數改為 `protected` - 強制使用單例
4. ✅ 移除 `initialize()` 方法 - 配置在構造函數中設定一次
5. ✅ `onHit()` 改為純函數 - 所有狀態從參數獲取

### **2. 子類別實現單例模式**

**Before:**
```typescript
export class ExplosiveProjectile extends ProjectileBasic {
    protected applyProjectileConfig(): void {
        this.pierceCount = 1;
        this.areaOfEffect = 80;
    }
}

// 使用
const projectile = new ExplosiveProjectile();
projectile.initialize('ExplosiveProjectile', weaponId, baseDamage);
```

**After:**
```typescript
export class ExplosiveProjectile extends ProjectileBasic {
    private static instance: ExplosiveProjectile;

    /**
     * 獲取單例實例
     */
    public static getInstance(): ExplosiveProjectile {
        if (!ExplosiveProjectile.instance) {
            ExplosiveProjectile.instance = new ExplosiveProjectile();
        }
        return ExplosiveProjectile.instance;
    }

    /**
     * 私有構造函數 - 強制使用 getInstance()
     */
    private constructor() {
        super();
    }

    protected applyProjectileConfig(): void {
        // 使用 Object.assign 繞過 readonly 限制（僅在構造函數中）
        (this as any).initialPierceCount = 1;
        (this as any).areaOfEffect = 80;
        (this as any).bounceCount = 0;
    }
}

// 使用
const projectile = ExplosiveProjectile.getInstance();  // ← 總是返回同一實例
```

**所有子類別更新：**
- ✅ `BasicProjectile.getInstance()`
- ✅ `ExplosiveProjectile.getInstance()`

- ✅ `FreezeProjectile.getInstance()`
- ✅ `PoisonExplosiveProjectile.getInstance()` (需要更新)

### **3. ProjectileRegistry 改為單例註冊表**

**Before:**
```typescript
export class ProjectileRegistry {
  private static registry: Map<string, new () => ProjectileBasic> = new Map();

  static {
    this.register('ExplosiveProjectile', ExplosiveProjectile);
  }

  public static create(className, weaponId, baseDamage): ProjectileBasic {
    const Constructor = this.registry.get(className);
    const projectile = new Constructor();  // ← 每次創建新實例
    projectile.initialize(className, weaponId, baseDamage);
    return projectile;
  }
}
```

**After:**
```typescript
export class ProjectileRegistry {
  /**
   * 註冊表：類名 -> getInstance 方法
   */
  private static registry: Map<string, () => ProjectileBasic> = new Map();

  static {
    this.register('ExplosiveProjectile', () => ExplosiveProjectile.getInstance());
    //                                     ▲
    //                          註冊獲取單例的函數
  }

  public static getInstance(className: string): ProjectileBasic {
    const getInstanceFn = this.registry.get(className);
    return getInstanceFn();  // ← 返回單例實例
  }
}
```

### **4. ProjectileFactory 簡化**

**Before:**
```typescript
export class ProjectileFactory {
    private static instances: Map<string, ProjectileBasic> = new Map();

    public static getProjectile(
        projectileClassName: string,
        weaponId: string,
        baseDamage: number
    ): ProjectileBasic {
        const cacheKey = `${projectileClassName}_${weaponId}_${baseDamage}`;

        // 檢查緩存
        if (this.instances.has(cacheKey)) {
            return this.instances.get(cacheKey)!;
        }

        // 使用註冊表創建實例
        const projectile = ProjectileRegistry.create(projectileClassName, weaponId, baseDamage);

        // 緩存實例
        this.instances.set(cacheKey, projectile);

        return projectile;
    }
}
```

**After:**
```typescript
export class ProjectileFactory {
    /**
     * 獲取投射物單例實例
     * 不需要 weaponId 和 baseDamage 參數！
     */
    public static getProjectile(projectileClassName: string): ProjectileBasic {
        return ProjectileRegistry.getInstance(projectileClassName);
    }
}
```

**簡化：**
- ❌ 移除 `instances` 緩存（單例自己管理）
- ❌ 移除 `weaponId`, `baseDamage` 參數（從 bullet 獲取）
- ✅ 直接返回單例

## 📚 設計模式分析

### **單例模式 (Singleton Pattern)**

```typescript
class ExplosiveProjectile {
    private static instance: ExplosiveProjectile;
    
    public static getInstance(): ExplosiveProjectile {
        if (!this.instance) {
            this.instance = new ExplosiveProjectile();
        }
        return this.instance;
    }
    
    private constructor() { }  // ← 私有構造函數
}
```

**優勢：**
- ✅ 確保全局只有一個實例
- ✅ 延遲初始化（Lazy Initialization）
- ✅ 全局訪問點

### **策略模式 (Strategy Pattern)**

```typescript
// ServerBullet 是環境（Context）
class ServerBullet {
    bulletType: string = 'ExplosiveProjectile';  // ← 指向策略
}

// ProjectileBasic 是抽象策略
abstract class ProjectileBasic {
    abstract onHit(...): AttackResult;
}

// ExplosiveProjectile 是具體策略（單例）
class ExplosiveProjectile extends ProjectileBasic {
    static getInstance() { ... }
}

// 使用
const strategy = ProjectileFactory.getProjectile(bullet.bulletType);
const result = strategy.onHit(bullet, enemy, gameRoom);
```

### **註冊表模式 (Registry Pattern)**

```typescript
class ProjectileRegistry {
    private static registry = new Map<string, () => ProjectileBasic>();
    
    static register(name, getInstanceFn) {
        this.registry.set(name, getInstanceFn);
    }
    
    static getInstance(name) {
        return this.registry.get(name)();
    }
}
```

## 🎯 總結

### **核心變更**

| 項目 | 重構前 | 重構後 |
|------|--------|--------|
| **實例創建** | 每次命中創建新實例 | 使用單例 |
| **狀態儲存** | ProjectileBasic 和 ServerBullet 都有 | 只在 ServerBullet |
| **參數傳遞** | weaponId, baseDamage 傳給 ProjectileBasic | 從 ServerBullet 獲取 |
| **性能** | 大量對象創建和銷毀 | 零創建開銷 |
| **內存** | O(n) n=命中次數 | O(1) |

### **設計理念**

```
ProjectileBasic = 不變的規則（單例）
ServerBullet    = 會變的狀態（每個子彈一個實例）

規則只需要一份，狀態需要多份
```
