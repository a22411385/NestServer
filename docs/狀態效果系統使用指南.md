## 系統概述

你的遊戲使用 **配置驅動 + 自動疊加** 的狀態效果系統，狀態效果會自動從武器屬性生成，並在命中時應用到目標單位。

### 🎯 核心特點

- ✅ **配置驅動**：從 Google Sheets `StatusEffectDefinitions` 表讀取定義
- ✅ **自動生成**：武器屬性自動轉換為狀態效果配置
- ✅ **自動疊加**：相同類型的效果會自動疊加層數
- ✅ **實時同步**：透過 Colyseus Schema 自動同步到客戶端
- ✅ **智能優化**：減少不必要的網絡同步，提升性能

### 3️⃣ 攻擊結果生成階段

**WeaponBasic.generateStatusEffects()**

```typescript
protected generateStatusEffects(): StatusEffectConfig[] {
    const allProperties = this.getAllProperties();
    const statusEffects: StatusEffectConfig[] = [];

    for (const prop of allProperties) {
        // 只處理 debuff/buff 類別
        if (prop.category !== 'debuff' && prop.category !== 'buff') {
            continue;
        }

        // 只包含有機率觸發的效果
        if (prop.probability > 0) {
            statusEffects.push({
                type: prop.id,                    // 'burn', 'freeze', 'stun'
                duration: prop.duration * 1000,   // 秒 → 毫秒（3000, 2000, 1500）
                value: prop.value,                // 20, 100, 0
                chance: prop.probability,         // 30, 20, 15
                category: prop.category           // 'debuff'
            });
        }
    }

    return statusEffects;
}
```

**分為近戰和遠程兩種流程：**

```typescript
// CombatSystem.processAttackByWeaponType()

    // 立即造成傷害

        this.applyStatusEffects(
            target,
            result.statusEffects,
            { x: hero.position.x, y: hero.position.y }

    }
}
```

#### 🏹 遠程武器（命中時應用）

```typescript
// BulletSystem.checkBulletCollisions()
const result = projectile.onHit(bullet, target, gameRoom);
if (result.success && result.statusEffects) {
    // 🆕 投射物命中時應用狀態效果

        const target = gameRoom.state.allUnits.get(targetId);
        if (target) {
            gameRoom.combatSystem.applyStatusEffects(
                target,
                result.statusEffects,
                bullet.getCurrentPosition()
            );
        }
    }
}
```

## 疊加機制

### 🔥 自動疊加系統

**CombatSystem.applyStatusEffects()**

```typescript
public applyStatusEffects(
    target: ServerGameUnit,
    effectConfigs: StatusEffectConfig[],
    attackerPosition?: { x: number; y: number }
): void {
    for (const config of effectConfigs) {
        // 1️⃣ 檢查機率觸發
        if (config.chance !== undefined) {
            const roll = Math.random() * 100;
            if (roll > config.chance) {
                continue; // 未觸發，跳過
            }
        }

        // 2️⃣ 檢查是否已存在相同類型的效果
        const existingEffect = this.findExistingEffect(target, config.type);
        
        if (existingEffect) {
            // 3️⃣ 疊加現有效果
            this.stackEffect(existingEffect, config);
            console.log(`🔥 ${config.type} 疊加至 ${existingEffect.stacks} 層`);
        } else {
            // 4️⃣ 創建新效果
            this.createNewEffect(target, config);
            console.log(`✨ ${config.type} 已應用 (持續 ${config.duration}ms)`);
        }
    }
}
```

### 📈 疊加規則

**stackEffect() 方法**

```typescript
private stackEffect(existingEffect: StatusEffect, config: StatusEffectConfig): void {
    // 1. 增加層數（不超過最大值）
    if (existingEffect.stacks < existingEffect.maxStacks) {
        existingEffect.stacks++; // 5 層上限（燃燒）
    }

    // 2. 刷新持續時間（取最長的）
    const currentRemainingTime = existingEffect.endTime - Date.now();
    if (config.duration > currentRemainingTime + 200) {
        existingEffect.endTime = Date.now() + config.duration;
    }

    // 3. 更新效果數值（取最大的）
    if (config.value > existingEffect.value * 1.1) {
        existingEffect.value = config.value;
    }
}
```

### 🎯 疊加優化

系統包含智能優化，減少不必要的同步：

```typescript
// ✅ 跳過無效疊加（已達最大層數且時間充足）
const isMaxStacks = existingEffect.stacks >= existingEffect.maxStacks;
const hasEnoughTime = remainingTime > config.duration * 0.5;

if (isMaxStacks && hasEnoughTime) {
    console.log(`⏭️ 跳過無效疊加: ${config.type}`);
    continue; // 不同步，減少網絡開銷
}
```

## 狀態效果配置

### 📝 StatusEffect Schema（同步到客戶端）

```typescript
export class StatusEffect extends Schema {
    @type("string") id: string = "";              // "burn_enemy_1"
    @type("string") type: string = "";            // "burn"
    @type("number") endTime: number = 0;          // 結束時間戳（客戶端可計算剩餘時間）
    @type("number") value: number = 0;            // 20（每秒傷害）
    @type("number") stacks: number = 1;           // 當前層數（1-5）
    @type("number") maxStacks: number = 5;        // 最大層數

    // 🔧 伺服器專用（不同步）
    public duration: number = 0;                  // 3000ms
    public startTime: number = 0;                 // 開始時間戳
    public _lastDamageTick?: number;              // 最後傷害時間
}
```

### 🎮 客戶端讀取

**ViteRPG/src/Game/Unit/ClientGameUnit.ts**

```typescript
public updateStatusEffects(time: number, delta: number): void {
    this.schemaData.statusEffects.forEach((effect, key) => {
        const remainingTime = effect.endTime - Date.now();
        
        // 根據效果類型顯示不同的視覺效果
        switch (effect.type) {
            case 'burn':
                this.showFireEffect(effect.stacks); // 火焰粒子效果
                break;
            case 'freeze':
                this.showFreezeEffect(); // 冰凍狀態
                this.sprite.tint = 0x00FFFF; // 藍色染色
                break;
            case 'slow':
                const slowValue = effect.value; // 減速 %
                this.currentMoveSpeed *= (1 - slowValue / 100);
                break;
        }
    });
}
```

## 實際案例

### 案例 1：火焰法杖（投射武器）

**武器配置（Google Sheets: WeaponConfigs）**

```csv
id,name,weaponClass,effectProperties
fireball,火球術,Fireball,burn
```

**效果定義（Google Sheets: StatusEffectDefinitions）**

```csv
id,displayName,category,duration,value,probability,maxStacks
burn,燃燒,debuff,3,20,30,5
```

**實際流程：**

```typescript
// 1. 玩家攻擊
hero.currentWeapon.attack(targets);

// 2. 生成火球子彈
const bullet = BulletFactory.createBullet({
    weaponId: 'fireball',
    damage: 50,
    statusEffects: [
        {
            type: 'burn',
            duration: 3000,    // 3 秒
            value: 20,         // 每秒 20 點傷害
            chance: 30,        // 30% 機率
            category: 'debuff'
        }
    ]
});

// 3. 火球命中敵人
ProjectileBasic.onHit(bullet, enemy, gameRoom);
// → 擲骰: Math.random() * 100 = 25 < 30 ✅ 觸發！

// 4. 應用燃燒效果
CombatSystem.applyStatusEffects(enemy, bullet.statusEffects);
// → 敵人獲得燃燒狀態（1 層）

// 5. 持續傷害計算（每秒）
StatusEffectSystem.update();
// → 每秒造成 20 點火焰傷害
// → 如果英雄有「火焰精通 +15%」
// → 實際傷害 = 20 × (1 + 0.15) = 23/秒
```

### 案例 3：狀態疊加（連續攻擊）

**持續攻擊燃燒敵人**

```typescript
// 第 1 次攻擊（0 秒）
applyStatusEffects(enemy, [{ type: 'burn', duration: 3000, value: 20 }]);
// → enemy.statusEffects['burn_enemy_1'] = { stacks: 1, value: 20, endTime: 3000 }

// 第 2 次攻擊（1 秒）
applyStatusEffects(enemy, [{ type: 'burn', duration: 3000, value: 20 }]);

// → enemy.statusEffects['burn_enemy_1'] = { stacks: 2, value: 20, endTime: 4000 }
// → 每秒傷害 = 20 × 2 = 40/秒

// 第 3 次攻擊（2 秒）
// → stacks: 3, endTime: 5000
// → 每秒傷害 = 20 × 3 = 60/秒

// 第 4 次攻擊（3 秒）
// → stacks: 4, endTime: 6000

// 第 5 次攻擊（4 秒）
// → stacks: 5, endTime: 7000（達到最大層數）

// 第 6 次攻擊（5 秒）
// → 已達最大層數且時間充足，跳過同步（優化）
```

## 系統流程圖

```
📦 武器配置階段
├─ Google Sheets: StatusEffectDefinitions
│  └─ burn, freeze, stun, poison, slow...
│
↓
📦 武器屬性生成階段
├─ WeaponPropertyService
│  └─ parseEffectProperties()
│     └─ PropertyValue[] (id, category, duration, value, probability)
│
↓
📦 攻擊結果生成階段
├─ WeaponBasic.generateStatusEffects()
│  └─ StatusEffectConfig[] (type, duration, value, chance, category)
│
↓
📦 攻擊命中應用階段
├─ 近戰武器 (立即)
│  └─ CombatSystem.applyStatusEffects()
│
├─ 遠程武器 (命中時)
│  └─ Bullet.statusEffects → ProjectileBasic.onHit()
│     └─ BulletSystem.checkBulletCollisions()
│        └─ CombatSystem.applyStatusEffects()
│
↓
📦 狀態效果管理階段
├─ CombatSystem.applyStatusEffects()
│  ├─ 1️⃣ 機率判定 (chance)
│  ├─ 2️⃣ 檢查已存在效果
│  ├─ 3️⃣ 疊加 or 創建新效果
│  └─ 4️⃣ 應用到 ServerGameUnit.statusEffects
│
↓
📦 持續效果處理階段
├─ StatusEffectSystem.update() (每 100ms)
│  ├─ burn/poison/bleed → 持續傷害
│  ├─ slow/freeze → 移動限制
│  ├─ stun → 完全控制
│  └─ 清理過期效果
│
↓
📦 客戶端同步階段
└─ Colyseus Schema 自動同步
   └─ ClientGameUnit.updateStatusEffects()
      ├─ 顯示視覺效果（火焰、冰霜、毒素）
      ├─ 應用移動限制
      └─ 顯示狀態圖示
```
