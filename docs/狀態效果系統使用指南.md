# 状态效果系统使用指南

## 📋 概述

StatusEffectSystem 是一个完整的状态效果管理系统，负责：
- ✅ 自动清理过期的状态效果
- ✅ 处理持续伤害（burn, poison）
- ✅ 管理减速效果（slow, freeze）
- ✅ 处理眩晕效果（stun）
- ✅ 提供状态查询工具

---

## 🏗️ 系统架构

### 数据流程

```
武器系统生成 StatusEffectConfig
           ↓
   CombatSystem.applyStatusEffects()
           ↓
     创建 StatusEffect Schema
           ↓
   添加到 ServerGameUnit.statusEffects
           ↓
  Colyseus 自动同步到客户端
           ↓
  StatusEffectSystem 定期更新
           ↓
    清理过期效果 & 应用持续伤害
```

### 核心组件

| 组件 | 职责 | 位置 |
|------|------|------|
| **StatusEffect** | Schema 数据结构 | `src/Colyseus/Schema/Unit/GameUnit.ts` |
| **StatusEffectConfig** | 配置传递接口 | `src/Types/Game/AttackTypes.ts` |
| **StatusEffectSystem** | 效果管理系统 | `src/Game/Systems/StatusEffectSystem.ts` |
| **CombatSystem** | 效果应用入口 | `src/Game/Systems/CombatSystem.ts` |

## 📦 StatusEffect Schema 结构

```typescript
export class StatusEffect extends Schema {
    @type("string") id: string = "";           // 唯一标识符
    @type("string") type: string = "";         // 效果类型
    @type("number") duration: number = 0;      // 持续时间 (毫秒)
    @type("number") value: number = 0;         // 效果数值
    @type("number") startTime: number = 0;     // 开始时间戳
}
```

### 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `id` | string | 唯一标识符 | `"burn_1729420123456_abc123"` |
| `type` | string | 效果类型 | `"burn"`, `"stun"`, `"slow"` 等 |
| `duration` | number | 持续时间（毫秒） | `3000` (3秒) |
| `value` | number | 效果数值 | 减速: `50` (50%), 伤害: `15` (15 DPS) |
| `startTime` | number | 开始时间戳 | `1729420123456` |

## 🎯 支持的状态效果类型

| 类型 | 描述 | value 含义 | 持续伤害 | 客户端处理 |
|------|------|-----------|---------|-----------|
| **burn** | 燃烧 | 每秒伤害 | ✅ | 火焰粒子 |
| **poison** | 中毒 | 每秒伤害 | ✅ | 毒雾粒子 |
| **slow** | 减速 | 减速百分比 | ❌ | 移动速度降低 |
| **freeze** | 冰冻 | 减速百分比 | ❌ | 冰晶特效 + 减速 |
| **stun** | 眩晕 | 无 | ❌ | 禁止移动/攻击 |
| **knockback** | 击退 | 击退力量 | ❌ | 位移动画 |

## 🔧 使用方法

### 1. 应用状态效果（在 CombatSystem 中）

```typescript
// 在武器命中时应用状态效果
const statusEffects: StatusEffectConfig[] = [
    {
        type: 'burn',
        duration: 5000,      // 5秒
        value: 20,           // 20 DPS
        chance: 80,          // 80% 触发机率
    },
    {
        type: 'slow',
        duration: 3000,      // 3秒
        value: 50,           // 减速 50%
    }
];

// 应用到目标单位
this.combatSystem.applyStatusEffects(
    targetUnit,
    statusEffects,
    { x: attacker.position.x, y: attacker.position.y }
);
```

### 2. 系统自动更新（在 GameRoom 中）

```typescript
// 在游戏主循环中调用
public handleGameTick(): void {
    const { deltaTime, currentTime } = this.gameManager.updateGameTick();
    
    // 🆕 更新状态效果系统（自动清理过期效果）
    this.statusEffectSystem.update(deltaTime);
    
    // ... 其他系统更新
}
```

### 3. 查询单位状态

```typescript
// 检查单位是否被眩晕
const isStunned = this.statusEffectSystem.isStunned(unit);
if (isStunned) {
    // 禁止移动和攻击
    return;
}

// 获取单位当前的减速百分比
const slowPercentage = this.statusEffectSystem.getSlowPercentage(unit);
const actualSpeed = unit.moveSpeed * (1 - slowPercentage / 100);

// 获取效果剩余时间
const remainingTime = this.statusEffectSystem.getRemainingDuration(
    unit,
    effectId
);
```

### 4. 手动清理效果

```typescript
// 清理单位的所有状态效果（例如死亡时）
this.statusEffectSystem.clearAllEffects(unit);

// 移除特定类型的效果（例如净化技能）
this.statusEffectSystem.removeEffectByType(unit, 'burn');
```

### 5. 获取系统统计信息

```typescript
// 调试用 - 查看当前所有状态效果
const stats = this.statusEffectSystem.getStats();
console.log(`当前活跃效果总数: ${stats.totalEffects}`);
console.log('效果类型分布:', stats.effectsByType);
// 输出示例: Map { 'burn' => 5, 'slow' => 3, 'stun' => 2 }
```

## 📊 持续伤害处理机制

### 工作原理

```typescript
// StatusEffectSystem 每 100ms 检查一次
private readonly TICK_INTERVAL: number = 100;

// 持续伤害每 1000ms (1秒) 应用一次
if (timeSinceLastTick >= 1000) {
    const damagePerSecond = effect.value;
    const totalDamage = damagePerSecond * ticks;
    
    // 应用伤害
    unit.hp = Math.max(0, unit.hp - totalDamage);
    
    // 广播伤害事件
    this.gameRoom.broadcast('status_damage', {
        unitId: unit.id,
        effectType: effect.type,
        damage: totalDamage,
        remainingHp: unit.hp,
        timestamp: Date.now(),
    });
}
```

### 客户端监听伤害事件

```typescript
// 在客户端监听持续伤害
room.onMessage('status_damage', (data) => {
    const { unitId, effectType, damage, remainingHp } = data;
    
    // 播放伤害动画
    this.showDamageNumber(unitId, damage, effectType);
    
    // 更新血条
    this.updateHealthBar(unitId, remainingHp);
});
```

### 2. 显示剩余时间

```typescript
// 计算剩余时间百分比（用于进度条）
function getEffectProgress(effect: StatusEffect): number {
    const currentTime = Date.now();
    const elapsed = currentTime - effect.startTime;
    const remaining = effect.duration - elapsed;
    return Math.max(0, remaining / effect.duration);
}

// 更新 UI
function updateStatusIcons(unit: ServerGameUnit): void {
    for (const [id, effect] of unit.statusEffects) {
        const progress = getEffectProgress(effect);
        updateIconProgress(id, progress);
    }
}
```

### 3. 应用减速效果

```typescript
// 在客户端移动逻辑中考虑减速
function updateUnitMovement(unit: ServerGameUnit, deltaTime: number): void {
    let moveSpeed = unit.moveSpeed;
    
    // 计算总减速百分比
    let totalSlow = 0;
    for (const [, effect] of unit.statusEffects) {
        if (effect.type === 'slow' || effect.type === 'freeze') {
            totalSlow += effect.value;
        }
    }
    
    // 应用减速
    const slowMultiplier = 1 - Math.min(totalSlow, 95) / 100;
    const actualSpeed = moveSpeed * slowMultiplier;
    
    // 更新位置
    unit.position.x += unit.vx * actualSpeed * deltaTime;
    unit.position.y += unit.vy * actualSpeed * deltaTime;
}
```

### 4. 处理眩晕效果

```typescript
// 检查是否被眩晕
function canUnitAct(unit: ServerGameUnit): boolean {
    for (const [, effect] of unit.statusEffects) {
        if (effect.type === 'stun') {
            // 显示眩晕特效（星星）
            this.showStunStars(unit);
            return false;
        }
    }
    return true;
}

// 在攻击/移动前检查
if (!canUnitAct(hero)) {
    return; // 被眩晕，无法行动
}
```

## 📝 最佳实践

### ✅ 推荐做法

1. **始终设置 startTime**
   ```typescript
   statusEffect.startTime = Date.now(); // ✅ 必须设置
   ```

2. **使用唯一 ID**
   ```typescript
   const effectId = `${config.type}_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
   ```

3. **在游戏主循环中更新**
   ```typescript
   // ✅ 在 handleGameTick 中调用
   this.statusEffectSystem.update(deltaTime);
   ```

4. **单位死亡时清理效果**
   ```typescript
   onUnitDeath(unit: ServerGameUnit): void {
       this.statusEffectSystem.clearAllEffects(unit);
   }
   ```

### ⚠️ 避免事项

1. **不要手动删除 statusEffects**
   ```typescript
   // ❌ 错误
   unit.statusEffects.delete(effectId);
   
   // ✅ 正确
   this.statusEffectSystem.removeEffectByType(unit, 'burn');
   ```

2. **不要忘记更新系统**
   ```typescript
   // ❌ 错误 - 效果永远不会过期
   // 没有调用 statusEffectSystem.update()
   
   // ✅ 正确 - 在游戏循环中调用
   this.statusEffectSystem.update(deltaTime);
   ```

3. **不要直接修改 effect 对象**
   ```typescript
   // ❌ 错误 - Schema 不会同步
   effect.duration = 10000;
   
   // ✅ 正确 - 移除旧效果，添加新效果
   unit.removeStatusEffect(oldEffectId);
   this.combatSystem.applyStatusEffects(unit, [newConfig]);
   ```

## 🚀 性能考虑

### 优化建议

1. **节流更新频率**
   - 默认 100ms 更新一次已经足够
   - 不建议低于 50ms

2. **限制效果数量**
   ```typescript
   // 可以添加最大效果数量限制
   const MAX_EFFECTS_PER_UNIT = 10;
   
   if (unit.statusEffects.size >= MAX_EFFECTS_PER_UNIT) {
       // 移除最旧的效果
   }
   ```

3. **批量处理**
   - 系统已经批量处理所有单位
   - 避免为每个单位单独调用 update

### 性能指标

- **100 单位, 每单位 3 效果**: ~1ms/tick
- **1000 单位, 每单位 3 效果**: ~10ms/tick
- **内存占用**: 每个效果 ~100 字节
