# 物品系統完整指南

## 📋 系統概覽

RPG 物品系統是一個統一的物品管理框架，支持多種物品類型的創建、管理和交易。系統採用統一的 ServerItem 基類，實現了完整的物品生命週期管理。

### 🎯 核心特性

- **統一物品基類**：所有物品繼承自 ServerItem
- **多物品類型支持**：武器、消耗品、材料、裝備等
- **智能掉落系統**：基於敵人等級的物品掉落
- **NPC 商店系統**：完整的交易和商店管理
- **客戶端同步**：實時物品狀態同步
- **物品定位系統**：智能名稱匹配和搜索
- **統一 ID 管理**：避免 ID 衝突的唯一標識符

## 🏗️ 系統架構

### 三層架構設計

```
🎮 控制層 (Controller)  - ItemController, ShopController
⚙️  服務層 (Service)     - ItemService, ShopService
📊 實體層 (Entity)       - ServerItem, ItemConfig, ShopConfig
```

#### 核心組件

- **ServerItem**: 統一物品基類
- **DropSystem**: 物品掉落管理系統
- **ShopService**: NPC 商店服務
- **UniqueIdGenerator**: 統一 ID 生成器
- **ItemNameMatcher**: 物品名稱智能匹配

## 🎁 掉落系統詳解

### 掉落機制

```typescript
class DropSystem {
    // 主掉落處理邏輯
    async handleEnemyDeath(enemy: ServerEnemy, room: GameRoom): Promise<ServerItem[]> {
        const dropChance = this.calculateDropChance(enemy.level);
        
        if (Math.random() < dropChance) {
            return this.generateDrops(enemy);
        }
        
        return [];
    }
    
    // 掉落機率計算
    private calculateDropChance(enemyLevel: number): number {
        const baseDropRate = 0.6; // 60% 基礎掉落率
        const levelBonus = enemyLevel * 0.002; // 每級 +0.2%
        return Math.min(1.0, baseDropRate + levelBonus);
    }
}
```

### 掉落類型分配

- **武器掉落**: 40% 機率
- **材料掉落**: 35% 機率  
- **消耗品掉落**: 20% 機率
- **特殊物品**: 5% 機率

## 🔍 物品名稱智能匹配

### 名稱匹配算法

```typescript
class ItemNameMatcher {
    // 智能匹配物品名稱
    findBestMatch(inputName: string, availableItems: ServerItem[]): ServerItem | null {
        const matches = availableItems.map(item => ({
            item,
            score: this.calculateSimilarity(inputName, item.name)
        }));
        
        // 找到最佳匹配
        const bestMatch = matches
            .filter(m => m.score > 0.6) // 相似度閾值
            .sort((a, b) => b.score - a.score)[0];
            
        return bestMatch?.item || null;
    }
}
```

### 支援的匹配類型

- **完全匹配**: 名稱完全相同
- **部分匹配**: 包含關鍵字
- **模糊匹配**: 相似度算法
- **別名匹配**: 支援物品別名

## 🛠️ 唯一 ID 系統

### ID 生成策略

```typescript
class UniqueIdGenerator {
    // 物品 ID 生成
    static generateItemId(): string {
        const timestamp = Date.now().toString(36);
        const machineId = this.getMachineId();
        const counter = (this.counter++).toString(36);
        return `item_${timestamp}_${machineId}_${counter}`;
    }
    
    // 武器 ID 生成  
    static generateWeaponId(): string {
        return `weapon_${this.generateSecureSeed()}`;
    }
    
    // 材料 ID 生成
    static generateMaterialId(): string {
        return `material_${this.generateSecureSeed()}`;
    }
}
```

### ID 格式說明

- **物品 ID**: `item_{timestamp36}_{machineId}_{counter36}`
- **武器 ID**: `weapon_{secureHash}`
- **材料 ID**: `material_{secureHash}`
- **消耗品 ID**: `consumable_{secureHash}`

### 記憶體管理

```typescript
// 物品池管理
class ItemPool {
    private pool = new Map<string, ServerItem[]>();
    
    // 取得可重用物品
    acquire(type: string): ServerItem {
        const items = this.pool.get(type) || [];
        return items.pop() || new ServerItem({type});
    }
    
    // 回收物品到池中
    release(item: ServerItem): void {
        item.reset(); // 重置狀態
        const items = this.pool.get(item.type) || [];
        items.push(item);
        this.pool.set(item.type, items);
    }
}
```
