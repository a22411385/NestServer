# 子彈屬性擴展快速指南

## 🚀 5 分鐘快速添加新子彈屬性

### 步驟 1: 在 `BulletCreateConfig` 定義屬性

```typescript
// src/Types/Game/BulletTypes.ts
export interface BulletCreateConfig {
    // ... 現有屬性 ...
    
    yourNewProperty?: number; // 你的新屬性描述
}
```

### 步驟 2: 在 `ServerBullet` 添加屬性

```typescript
// src/Colyseus/Schema/Bullet.ts
export class ServerBullet extends Schema {
    // ... 現有屬性 ...
    
    yourNewProperty: number = 0; // 默認值
}
```

### 步驟 3: 在 `applyExtendedConfig()` 註冊

```typescript
// src/Colyseus/Schema/Bullet.ts
public applyExtendedConfig(config: {
    // ... 現有屬性 ...
    yourNewProperty?: number; // ← 添加類型定義
}): void {
    const extendedProperties = [
        // ... 現有屬性 ...
        'yourNewProperty', // ← 添加到列表
    ];
    
    // 自動處理 ✨
}
```

### 步驟 4: 在武器中使用

```typescript
// 在任何 ProjectileWeapon 子類中
protected getAmmoOverride() {
    return {
        yourNewProperty: 123, // ← 設置值
    };
}
```

## ✅ 完成！

`BulletFactory` 會自動處理新屬性，無需修改任何工廠代碼！

## 🔧 故障排除

### Q: 新屬性沒有生效？

**檢查清單**:
- [ ] 在 `BulletCreateConfig` 中定義了屬性
- [ ] 在 `ServerBullet` 中添加了屬性
- [ ] 在 `applyExtendedConfig()` 的**類型定義**中添加了屬性
- [ ] 在 `applyExtendedConfig()` 的**屬性列表**中添加了屬性名
- [ ] 在武器的 `getAmmoOverride()` 中設置了值

### Q: TypeScript 報錯？

確保屬性名稱在以下位置**完全一致**:
1. `BulletCreateConfig` 接口
2. `ServerBullet` 類
3. `applyExtendedConfig()` 參數類型
4. `extendedProperties` 數組（字符串形式）

### Q: 屬性值總是默認值？

檢查 `getAmmoOverride()` 是否正確返回配置：
```typescript
protected getAmmoOverride() {
    return {
        yourNewProperty: someValue, // ← 確保有返回值
    };
}
```
